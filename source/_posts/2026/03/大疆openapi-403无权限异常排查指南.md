## 问题现象

调用大疆司空 2 OpenAPI 接口时，返回 **403 无权限异常**，接口调用失败。本文整理了官方文档推荐的排查步骤，帮助你快速定位并解决问题。

## 排查步骤

按照以下步骤逐一检查，大多数情况都能快速定位问题：

### 1. 检查 Token 生成人是否在项目中

Token 是与创建用户绑定的，如果用户不在项目中，Token 会自动失效。

**检查点：**
- 登录大疆司空管理后台
- 进入「项目设置」→「项目成员」
- 确认生成 Token 的用户仍然在成员列表中

如果用户已经离职或者被移除出项目，需要由现有管理员重新生成 Token。

### 2. 检查用户权限是否足够

生成 Token 的用户必须具有**项目管理员**权限，否则无法调用 OpenAPI。

**检查点：**
- 在项目成员列表中查看该用户的角色
- 确认角色是「项目管理员」而非「普通成员」「查看者」

**解决方法：**
如果权限不足，请联系项目管理员提升权限，或者由管理员直接生成 Token。

### 3. 请求头必须携带 X-Project-Uuid

大多数项目相关的 OpenAPI 接口都需要在请求头中携带项目 UUID，否则会直接返回 403。

#### 正确示例：

```java
requestHeaders.put("X-User-Token", "your-access-token");
requestHeaders.put("X-Project-Uuid", "your-project-uuid-here");
```

#### 关键点：
- **Header Name**：必须是 `X-Project-Uuid`，注意大小写和连字符
- **格式要求**：必须是合法的 UUID 格式
- **获取方式**：调用「获取项目列表」接口得到所有项目 UUID

### 4. 获取项目 UUID

调用以下接口可以获取当前 Token 有权限访问的所有项目列表：

```
GET https://es-flight-api-cn.djigate.com/openapi/v0.1/project
```

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "projects": [
      {
        "uuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
        "name": "我的项目",
        "createdAt": "2026-01-01T00:00:00Z"
      }
    ]
  }
}
```

从响应中取出 `uuid` 字段，就是你需要的 `X-Project-Uuid`。

## 完整检查清单

| 检查项 | 状态 | 说明 |
|--------|------|------|
| Token 生成人在项目成员列表中 | □ | 移除/离职需要重新生成 |
| Token 生成人是项目管理员 | □ | 普通成员无 API 调用权限 |
| 请求头包含 `X-Project-Uuid` | □ | 注意大小写和拼写 |
| `X-Project-Uuid` 是正确的 UUID 格式 | □ | 不能使用项目名称或其他ID |
| 域名与区域匹配（中国区使用 `*-cn.djigate.com`） | □ | 区域不匹配也会导致 403 |
| 服务器 IP 在白名单中 | □ | 配置了白名单的需要检查 |

## 查看 Token 生成人

在大疆司空开发者界面，可以直接查看当前 Token 是由哪个用户生成的：

1. 进入「企业管理」→「开发者」
2. 找到你的应用，点击「查看」
3. 在 Token 管理列表中，可以看到每条 Token 的创建人信息

## 总结

大疆 OpenAPI 返回 403 无权限异常，90% 以上都是由以下三个原因导致：

1. **Token 创建人不在项目中**——重新生成 Token
2. **Token 创建人不是管理员**——提升权限或换管理员生成
3. **缺少 X-Project-Uuid 请求头**——添加正确的项目 UUID

按照本文的步骤检查一遍，基本都能解决问题。
