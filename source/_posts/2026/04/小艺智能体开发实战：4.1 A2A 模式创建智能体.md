# 小艺智能体开发实战：A2A 模式创建智能体

## 前言

随着 AI 大模型的快速发展，智能体（Agent）开发成为热门方向。本文将介绍如何基于 A2A（Agent-to-Agent）通信协议，从零开始创建一个智能体应用。

A2A 协议是一种基于 JSON-RPC 2.0 的通信协议，采用 Streamable HTTP + SSE 流式输出，适用于构建响应式的 AI 智能体应用。

## 什么是 A2A 协议

A2A（Agent-to-Agent）通信协议是一种轻量级的智能体通信标准，具有以下特点：

- **基于 JSON-RPC 2.0**：结构清晰，易于实现和调试
- **支持 SSE 流式输出**：实时推送任务状态和结果
- **统一端点设计**：所有方法通过单一端点 `/agent/message` 路由
- **会话状态管理**：内置 Session 机制，支持多轮对话

## 定义数据模型

```python
# models/schemas.py
from pydantic import BaseModel
from typing import Optional, Any

# JSON-RPC 请求
class JsonRpcRequest(BaseModel):
    jsonrpc: str = "2.0"
    id: Optional[int | str] = None
    method: Optional[str] = None
    sessionId: Optional[str] = None
    params: Optional[dict[str, Any]] = None

# JSON-RPC 响应
class JsonRpcResponse(BaseModel):
    jsonrpc: str = "2.0"
    id: Optional[int | str] = None
    result: Optional[dict[str, Any]] = None
    error: Optional[dict] = None
```

## 实现 Agent 路由

```python
# routes/agent_routes.py
from fastapi import APIRouter, Request, Header
from fastapi.responses import JSONResponse
import uuid

from models.schemas import JsonRpcRequest, JsonRpcResponse

router = APIRouter(prefix="/agent", tags=["agent"])

# 会话存储（生产环境建议使用 Redis）
agent_sessions = {}

@router.post("/message")
async def handle_agent_message(
    request: Request,
    agent_session_id: str | None = Header(None, alias="agent-session-id"),
):
    """统一的 Agent 消息处理接口"""
    body = await request.json()
    jsonrpc_request = JsonRpcRequest(**body)
    method = jsonrpc_request.method
    
    # 根据 method 路由到不同处理方法
    if method == "initialize":
        return await handle_initialize(jsonrpc_request)
    elif method == "message/stream":
        return await handle_message_stream(jsonrpc_request, agent_session_id)
    else:
        return JSONResponse(
            status_code=400,
            content={"error": f"Method not found: {method}"}
        )

async def handle_initialize(request: JsonRpcRequest):
    """初始化会话"""
    session_id = uuid.uuid4().hex
    agent_sessions[session_id] = {"status": "active"}
    
    return JSONResponse(content={
        "jsonrpc": "2.0",
        "id": request.id,
        "result": {
            "agentSessionId": session_id,
            "agentSessionTtl": 604800  # 7 天
        }
    })
```
