# 小艺智能体开发实战：常见问题

## 前言

在开发和部署智能体应用的过程中，难免会遇到各种问题。本文整理了常见问题及其解决方案，帮助你快速排查和解决问题。


## 流式输出不生效

接口返回的json数据中，即使成功，也需要有 "error.code" 字段，且为 code 的 值 0

```json
{
  "error": {
      "code": 0,
      "message": "success"
  }
}
```
