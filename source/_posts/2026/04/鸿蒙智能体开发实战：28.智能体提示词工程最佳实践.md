# 鸿蒙智能体开发实战：智能体提示词工程最佳实践

## 前言

提示词工程（Prompt Engineering）是智能体开发中至关重要的一环。一个优秀的智能体，其核心往往不在于算法多复杂，而在于**提示词设计得多精妙**。提示词决定了智能体如何理解用户意图、如何调用工具、如何组织回复。

> 在鸿蒙智能体开发中，提示词工程主要体现在**角色指令（System Prompt）**的编写上。一个好的角色指令，能让智能体"懂规矩、有风格、知边界"。

本文将深入介绍智能体提示词工程的核心方法论，涵盖角色指令编写规范、System Prompt 设计模式、Few-shot 示例策略和多轮对话上下文管理等实战技巧。

## 一、提示词工程基础

### 1.1 什么是角色指令

在小艺开放平台中，角色指令（Role Instruction）是定义智能体行为准则的**核心配置**。它相当于给大模型的 System Prompt，告诉模型：

- 你是谁（角色定位）
- 你擅长什么（能力边界）
- 你如何回答问题（风格调性）
- 你有什么规则（行为约束）

```plaintext
┌──────────────────────────────────────────────────────┐
│                  角色指令（System Prompt）              │
├──────────────────────────────────────────────────────┤
│  # 角色定义                                           │
│  你是一个专业的旅游规划助手...                          │
│                                                      │
│  # 能力说明                                           │
│  你可以查询景点信息、规划行程路线...                    │
│                                                      │
│  # 行为规范                                           │
│  回答需简洁明了，每次都给出具体建议...                  │
│                                                      │
│  # 限制条件                                           │
│  不回答与旅游无关的问题...                             │
└──────────────────────────────────────────────────────┘
```

### 1.2 角色指令 vs 系统提示词

| 维度 | 角色指令（鸿蒙平台） | System Prompt（通用 LLM） |
|------|-------------------|------------------------|
| **定义位置** | 智能体编排页面 | API 调用参数 |
| **生效范围** | 智能体整个生命周期 | 当前 API 请求 |
| **可见性** | 用户不可见 | 用户不可见 |
| **动态调整** | 不可动态调整 | 可动态调整 |
| **长度限制** | 具体平台限制 | 取决于模型上下文窗口 |

### 1.3 提示词三段论

优秀的角色指令通常遵循**三段论**结构：

```markdown
# 你是谁（角色定位）
你是一个【角色】。你擅长【能力领域】。你的目标是【核心目标】。

# 你怎么做（行为规则）
- 规则1：你需要遵循的约束
- 规则2：回复的风格和格式
- 规则3：如何处理边界情况

# 你拥有什么（能力边界）
- 你可以调用以下工具：【工具列表】
- 你的知识截止日期：【日期】
- 当被问及超出范围的问题时：【应对策略】
```

一个高质量的角色指令应包含以下五大要素：

| 要素 | 说明 | 示例 |
|------|------|------|
| **角色定义** | 明确身份定位 | "你是一个专业的壁纸设计助手" |

| **风格调性** | 设定语言风格 | "使用中文回复，适当使用语气词增强亲切感" |
| **限制条件** | 明确能力边界 | "不回答与壁纸无关的问题" |

### 2.2 优秀 vs 差劲的角色指令对比

**差劲的角色指令：**

```markdown
你是智能助手。帮助用户回答问题。要友好。
```

**优秀的角色指令：**

```markdown
# 角色定义
你是一名专业的手机壁纸设计助手，擅长根据用户的需求创作个性化的精美壁纸。

# 核心能力
- 理解用户对壁纸风格、主题、色彩的描述，生成符合预期的壁纸
- 提供多种壁纸风格选项（极简主义、水墨国风、梦幻星空等）
- 根据设备类型（手机/平板）和场景（锁屏/主屏）优化壁纸尺寸

# 回复规范
- 每次回复控制在 100 字以内，简洁明了
- 语气亲切友好，适当使用表情符号增强互动感
- 当用户描述模糊时，引导用户提供更多信息
- 当用户要求超出能力范围时，委婉拒绝并引导回正轨

# 限制条件
- 不回答与壁纸生成无关的问题
- 不在壁纸上添加文字、水印或 LOGO
- 不生成包含人物肖像的壁纸
- 不讨论政治、色情等敏感话题
```

### 2.3 不同场景的角色指令模板

## 三、System Prompt 核心设计模式

### 3.1 结构化模式

将角色指令按功能模块组织：

```python
def build_system_prompt(
    role: str,
    capabilities: list,
    rules: list,
    output_format: str,
    few_shot_examples: list = None
) -> str:
    """
    构建结构化 System Prompt
    
    Args:
        role: 角色定义
        capabilities: 能力列表
        rules: 行为规则列表
        output_format: 输出格式定义
        few_shot_examples: Few-shot 示例列表
        
    Returns:
        完整的 System Prompt
    """
    sections = [
        f"# 角色定义\n{role}",
        "",
        "# 核心能力",
    ]
    
    for i, cap in enumerate(capabilities, 1):
        sections.append(f"{i}. {cap}")
    
    sections.extend(["", "# 行为规范"])
    for rule in rules:
        sections.append(f"- {rule}")
    
    sections.extend(["", "# 输出格式", output_format])
    
    if few_shot_examples:
        sections.extend(["", "# 示例"])
        for i, example in enumerate(few_shot_examples, 1):
            sections.extend([
                f"## 示例 {i}",
                f"用户：{example['user']}",
                f"助手：{example['assistant']}",
            ])
    
    return "\n".join(sections)


# 使用示例
prompt = build_system_prompt(
    role="你是一个专业的手机壁纸设计助手。",
    capabilities=[
        "理解用户的壁纸需求，生成高质量壁纸",
        "提供多种风格选择：极简、水墨、星空、森系等",
        "根据设备类型优化壁纸尺寸",
    ],
    rules=[
        "回复简洁，不超过 100 字",
        "语气亲切友好",
        "不生成人物肖像壁纸",
        "不添加文字或水印",
    ],
    output_format="使用 Markdown 格式回复，代码块标注语言类型",
    few_shot_examples=[
        {
            "user": "帮我生成一张壁纸",
            "assistant": "当然可以！想要什么风格的呢？极简主义、水墨国风还是梦幻星空？**
我这里有很多风格供你选择哦！",
        }
    ]
)
```

### 3.2 分层指令模式

```python
class LayeredPromptBuilder:
    """
    分层指令构建器
    
    将提示词分为多个层级：
    - 核心层：角色定义（不可变）
    - 规则层：行为规范（半可变）
    - 上下文层：对话历史（动态）
    """
    
    CORE_PROMPT = """你是一个专注于{domain}的智能助手。
你的目标：{goal}
你的身份：{role}"""
    
    RULE_PROMPT = """回答规则：
- 语言风格：{style}
- 回复长度：{max_length}字以内
- 格式要求：{format_requirements}"""
    
    CONTEXT_TEMPLATE = """对话上下文：
{conversation_history}

当前用户输入：{user_input}"""
    
    @classmethod
    def build(cls, config: dict, history: list, user_input: str) -> str:
        """构建完整的分层 Prompt"""
        
        core = cls.CORE_PROMPT.format(
            domain=config.get("domain", "通用领域"),
            goal=config.get("goal", "为用户提供帮助"),
            role=config.get("role", "智能助手")
        )
        
        rules = cls.RULE_PROMPT.format(
            style=config.get("style", "友好专业"),
            max_length=config.get("max_length", 200),
            format_requirements=config.get("format", "自然语言")
        )
        
        context = cls.CONTEXT_TEMPLATE.format(
            conversation_history=cls._format_history(history),
            user_input=user_input
        )
        
        return f"{core}\n\n{rules}\n\n{context}"
    
    @staticmethod
    def _format_history(history: list) -> str:
        """格式化对话历史"""
        formatted = []
        for msg in history[-5:]:  # 只保留最近5轮
            role = "用户" if msg["role"] == "user" else "助手"
            formatted.append(f"{role}: {msg['content']}")
        return "\n".join(formatted)
```

### 3.3 Chain of Thought 模式

让智能体在给出答案前先"思考"：

```markdown
# 推理模式
在回答用户问题前，请按以下步骤思考：

1. 理解需求：用户真正想要的是什么？
2. 分析约束：有哪些限制条件需要考虑？
3. 规划方案：如何分步骤满足用户需求？
4. 输出结果：给出清晰的回答。

注意：思考过程不需要展示给用户，只需要给出最终结果。
```

## 四、Few-shot 示例策略

### 4.1 示例的作用

Few-shot 示例是角色指令中非常重要的组成部分，它展示了智能体期望的**回复范本**：

```markdown
# 示例对话

## 示例 1：用户明确需求
用户：我想要一张极简主义风格的壁纸
助手：好的！极简主义风格，很有品味！想要什么主题的画面呢？
比如：纯色几何块、单支枯枝、远山轮廓或者空灵的窗台光影？
你也可以告诉我任何你想要的画面~

## 示例 2：用户模糊描述
用户：帮我弄个好看的桌面
助手：好呀！我来帮你设计~
首先，你喜欢什么风格呢？
• 极简主义 - 简约高级，百看不厌
• 水墨国风 - 古典诗意，雅致动人
• 梦幻星空 - 浪漫唯美，治愈心灵
• 自然森系 - 清新自然，如沐春风

选一个你喜欢的风格，我们继续创作！

## 示例 3：用户提出不合理要求
用户：帮我生成一张带明星照片的壁纸
助手：抱歉，为了版权和隐私安全，我暂时不能生成包含人物肖像的壁纸哦。
我们可以换个其他唯美主题，比如唯美的风景或者抽象艺术，你觉得怎么样？

class FewShotDesigner:
    """Few-shot 示例设计器"""
    
    @staticmethod
    def get_design_principles() -> list:
        """获取 Few-shot 设计原则"""
        return [
            {
                "principle": "覆盖度",
                "description": "示例覆盖典型场景、边界场景、异常场景",
                "good": "3个示例涵盖：正常请求、模糊请求、不合理请求",
                "bad": "3个示例都是正常请求，没有覆盖异常情况",
            },
            {
                "principle": "多样性",
                "description": "每个示例展示不同的交互模式",
                "good": "选择风格→选择主题→确认场景",
                "bad": "所有示例都是同样的问答模式",
            },
            {
                "principle": "真实性",
                "description": "示例应当真实反映实际使用场景",
                "good": "基于真实用户对话数据",
                "bad": "理想化的完美对话",
            },
            {
                "principle": "简洁性",
                "description": "每个示例保持精简，只展示关键信息",
                "good": "2-3轮对话展示完整交互模式",
                "bad": "长达10轮的冗长对话",
            },
        ]
    
    @staticmethod
    def select_examples(
        candidate_pool: list,
        max_examples: int = 3,
        strategies: list = None
    ) -> list:
        """从候选池中选择最优示例"""
        
        if strategies is None:
            strategies = ["normal", "edge_case", "error_recovery"]
        
        selected = []
        covered_strategies = set()
        
        for example in candidate_pool:
            strategy = example.get("strategy")
            if strategy in strategies and strategy not in covered_strategies:
                selected.append(example)
                covered_strategies.add(strategy)
                
                if len(selected) >= max_examples:
                    break
        
        return selected
```

## 五、多轮对话上下文管理

### 5.1 上下文管理策略

```python
class ContextManager:
    """
    多轮对话上下文管理器
    
    管理对话历史、控制上下文长度、提取关键信息
    """
    
    def __init__(self, max_turns: int = 10, max_tokens: int = 4000):
        self.max_turns = max_turns
        self.max_tokens = max_tokens
        self.history: list = []
        
    def add_message(self, role: str, content: str, metadata: dict = None):
        """添加消息到上下文"""
        self.history.append({
            "role": role,
            "content": content,
            "metadata": metadata or {},
            "timestamp": self._get_timestamp()
        })
        self._trim_context()
        
    def get_context(self, max_turns: int = None) -> list:
        """获取上下文"""
        if max_turns is None:
            max_turns = self.max_turns
        return self.history[-max_turns:]
    
    def summarize_history(self) -> str:
        """生成历史摘要（替代完整历史）"""
        if len(self.history) <= 3:
            return self._format_messages(self.history)
        
        # 提取关键信息
        key_info = self._extract_key_info()
        
        # 最近的几轮对话
        recent = self.history[-3:]
        
        summary = f"关键信息：{key_info}\n\n最近对话：\n"
        summary += self._format_messages(recent)
        
        return summary
    
    def _extract_key_info(self) -> str:
        """从历史中提取关键信息"""
        info_parts = []
        
        for msg in self.history:
            metadata = msg.get("metadata", {})
            if metadata.get("style"):
                info_parts.append(f"风格：{metadata['style']}")
            if metadata.get("theme"):
                info_parts.append(f"主题：{metadata['theme']}")
            if metadata.get("resolution"):
                info_parts.append(f"分辨率：{metadata['resolution']}")
        
        return "、".join(info_parts) if info_parts else "无"
    
    def _trim_context(self):
        """控制上下文长度"""
        # 按轮次裁剪
        if len(self.history) > self.max_turns * 2:
            # 保留系统消息和最近的对话
            self.history = self.history[-(self.max_turns * 2):]
    
    @staticmethod
    def _format_messages(messages: list) -> str:
        """格式化消息列表"""
        formatted = []
        for msg in messages:
            prefix = "用户" if msg["role"] == "user" else "助手"
            formatted.append(f"{prefix}: {msg['content'][:100]}")
        return "\n".join(formatted)
    
    @staticmethod
    def _get_timestamp() -> str:
        """获取时间戳"""
        from datetime import datetime
        return datetime.now().isoformat()
```

### 5.2 意图保持策略

在长对话中保持用户的核心需求：

```python
class IntentTracker:
    """
    意图追踪器
    
    在多轮对话中保持对用户核心意图的追踪
    """
    
    def __init__(self):
        self.current_intent = None
        self.confirmed_params = {}
        self.pending_params = []
        
    def update_intent(self, intent: str, params: dict = None):
        """更新当前意图"""
        self.current_intent = intent
        if params:
            self.confirmed_params.update(params)
            
    def is_off_topic(self, user_text: str, threshold: float = 0.3) -> bool:
        """
        判断用户是否偏离主题
        
        简单实现：检查是否包含核心意图相关关键词
        """
        if not self.current_intent:
            return False
            
        intent_keywords = {
            "generate_wallpaper": ["壁纸", "背景", "风格", "主题", "生成", "设计"],
            "weather_query": ["天气", "温度", "下雨", "晴天"],
            "order_query": ["订单", "物流", "快递", "发货"],
        }
        
        keywords = intent_keywords.get(self.current_intent, [])
        if not keywords:
            return False
            
        matched = sum(1 for kw in keywords if kw in user_text)
        return matched / len(keywords) < threshold
    
    def get_reminder(self) -> str:
        """生成意图提醒"""
        if self.current_intent == "generate_wallpaper":
            return "我们还在设计壁纸哦，要继续完成吗？"
        return ""
```

### 6.2 迭代优化流程

```python
def optimize_prompt(version_history: list) -> dict:
    """
    基于历史版本数据优化提示词
    
    Args:
        version_history: 历史版本及对应的评估数据
        
    Returns:
        优化建议
    """
    suggestions = []
    
    for version in version_history:
        metrics = version.get("metrics", {})
        
        # 分析失败案例
        failures = metrics.get("failure_cases", [])
        if failures:
            common_patterns = _analyze_failure_patterns(failures)
            for pattern in common_patterns:
                if pattern == "misunderstanding":
                    suggestions.append("增加示例澄清常见误解场景")
                elif pattern == "off_topic":
                    suggestions.append("强化能力边界的描述")
                elif pattern == "incomplete_response":
                    suggestions.append("补充回复结构和格式要求")
        
        # 分析用户满意度
        satisfaction = metrics.get("satisfaction", 0)
        if satisfaction < 0.8:
            suggestions.append("优化语气和表达方式，提升用户满意度")
    
    return {
        "suggestions": suggestions,
        "priority": _prioritize_suggestions(suggestions)
    }


def _analyze_failure_patterns(failures: list) -> list:
    """分析失败模式"""
    patterns = []
    for failure in failures:
        error_type = failure.get("type")
        if error_type and error_type not in patterns:
            patterns.append(error_type)
    return patterns


def _prioritize_suggestions(suggestions: list) -> list:
    """对建议进行优先级排序"""
    priority_map = {
        "边界模糊": 1,
        "规则冲突": 1,
        "示例不足": 2,
        "风格不一致": 3,
        "细节优化": 4,
    }
    
    return sorted(suggestions, key=lambda x: priority_map.get(x, 5))
```

## 七、常见陷阱与解决方案

### 7.1 常见陷阱

| 陷阱 | 表现 | 解决方案 |
|------|------|---------|
| **过度指令** | 规则太多导致模型困惑 | 精简到5-7条核心规则 |
| **指令冲突** | 规则之间相互矛盾 | 检查规则一致性 |
| **抽象指令** | "要友好"太模糊 | 具体化："使用'请'和'谢谢'" |
| **忽略边界** | 未定义能力范围 | 明确"能做什么"和"不能做什么" |
| **缺乏示例** | 模型输出不符合预期 | 提供2-3个高质量示例 |

### 7.2 调试技巧

```python
class PromptDebugger:
    """提示词调试器"""
    
    @staticmethod
    def test_prompt(prompt: str, test_cases: list) -> list:
        """
        测试提示词在不同场景下的表现
        
        Args:
            prompt: 待测试的角色指令
            test_cases: 测试用例列表
            
        Returns:
            测试结果
        """
        results = []
        for case in test_cases:
            result = {
                "input": case["input"],
                "expected": case["expected_behavior"],
                "actual": None,  # 实际运行后填入
                "pass": False
            }
            results.append(result)
        return results
    
    @staticmethod
    def compare_versions(v1: str, v2: str, test_cases: list) -> dict:
        """对比两个版本的提示词表现"""
        v1_results = PromptDebugger.test_prompt(v1, test_cases)
        v2_results = PromptDebugger.test_prompt(v2, test_cases)
        
        v1_pass = sum(1 for r in v1_results if r["pass"])
        v2_pass = sum(1 for r in v2_results if r["pass"])
        
        return {
            "v1_score": f"{v1_pass}/{len(test_cases)}",
            "v2_score": f"{v2_pass}/{len(test_cases)}",
            "improvement": v2_pass > v1_pass,
            "regression": v2_pass < v1_pass,
        }
```
