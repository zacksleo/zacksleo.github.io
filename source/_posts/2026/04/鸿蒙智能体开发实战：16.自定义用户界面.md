# 鸿蒙智能体开发实战：自定义用户界面

## 前言

一个优秀的智能体不仅要有强大的对话能力，还要有**出色的用户体验**。鸿蒙智能体平台提供了丰富的界面自定义功能，从背景图片、角色声音到快捷指令、开场对话，开发者可以像装修一间房子一样，精细地打造智能体的每一个交互细节。本文将全面介绍智能体界面自定义的各个方面。

## 界面自定义总览

智能体的用户界面自定义包含以下维度：

| 自定义项 | 作用 | 适用模式 |
|---------|------|---------|
| **背景图片** | 对话态和通话态的视觉沉浸感 | 所有模式 |
| **角色声音** | 语音交互的音色体验 | 所有模式 |
| **开场对话** | 首次进入智能体的引导语 | 所有模式 |
| **预置问题** | 引导用户快速体验智能体能力 | 所有模式 |
| **快捷指令** | 快速发起预设对话的入口 | 所有模式 |
| **输入文件设置** | 支持上传图片/文件 | 所有模式 |
| **A2A输出设置** | 卡片输出绑定 | A2A模式 |

## 背景图片

### 背景图片概述

背景图片功能允许开发者为智能体在小艺应用中增加对话和通话状态的背景图片，让对话时更加**沉浸**。

### 对话态背景

设置智能体对话状态下的背景图片，支持两种屏幕形态：

| 屏幕形态 | 说明 | 建议尺寸 |
|---------|------|---------|
| **竖屏背景** | 手机竖屏状态下的对话背景 | 9:16比例 |
| **宽屏背景** | 平板或横屏状态下的对话背景 | 16:9比例 |

```python
# 对话态背景配置示例
background_config = {
    "dialogue": {
        "portrait": "https://example.com/bg_portrait.jpg",  # 竖屏背景
        "landscape": "https://example.com/bg_landscape.jpg"  # 宽屏背景
    }
}
```

### 通话态背景

通话状态下的背景图片配置更加丰富，支持 Normal 和 ColdBoot 两种场景：

```python
# 通话态背景配置示例
call_background_config = {
    "call": {
        "normal": {
            "portrait": "https://example.com/call_normal_portrait.jpg",
            "landscape": "https://example.com/call_normal_landscape.jpg",
            "external_screen": "https://example.com/call_normal_external.jpg"
        },
        "cold_boot": {
            "portrait": "https://example.com/cold_boot_portrait.jpg",
            "landscape": "https://example.com/cold_boot_landscape.jpg",
            "external_screen": "https://example.com/cold_boot_external.jpg"
        }
    }
}
```

> **提示**：通话态背景支持视频和首帧图片配置，可以实现动态背景效果。

### 背景图片配置步骤

1. 进入智能体编排页面，找到**背景图片**配置区域
2. 选择**对话态**或**通话态**
3. 上传对应屏幕形态的图片/视频
4. 预览效果后保存

## 角色声音

### 声音配置

开发者可以在【角色声音】部分试听平台开放的音色并为智能体设置一个**默认音色**：

```json
{
  "voice_config": {
    "default_voice": "xiaoyi_warm",     // 默认音色
    "user_switch_enabled": true          // 是否允许用户切换
  }
}
```

### 用户切换控制

平台为开发者提供了【终端用户可以切换声音】开关：

- **开关打开**（默认）：该智能体支持用户在终端自主切换可用的智能体音色
- **开关关闭**：不支持用户在终端自主切换智能体音色，但支持使用自定义音色

> **应用场景**：如果你的智能体是一个特定角色的虚拟形象（如班主任、客服专员），建议关闭用户切换功能以保持角色一致性；如果是通用助手，建议开启让用户自由选择。

## 开场对话和预置问题

### 开场语

开场对话是**用户首次进入智能体后自动展示的引导信息**。它的主要目的是帮助用户理解智能体的用途或背景，以及如何与其进行交互：

```markdown
# 👋 你好！我是你的专属健康管理助手

我可以帮助你：
- **记录每日饮食**和运动情况
- 分析**健康数据趋势**
- 提供个性化的**健康建议**

> 开始对话前，请先告诉我您的年龄和身高体重~
```

### 预置问题

每个智能体最多可以设置**三个预置问题**，让用户通过点击快速体验智能体的能力：

```json
{
  "preset_questions": [
    "今天天气怎么样？",
    "帮我推荐一首适合跑步的音乐",
    "给我讲个笑话"
  ]
}
```

> **提示**：预置问题应选择最能体现智能体核心功能的典型问题，让用户第一眼就知道这个智能体擅长什么。

## 快捷指令

### 快捷指令概述

快捷指令配置完成后，用户可以通过点击快捷指令快速发起预设对话。每个智能体最多支持配置**十个快捷指令**和一个**动态快捷指令**。

### 快捷指令类型

| 类型 | 说明 | 预览支持 |
|------|------|---------|
| **文本** | 点击后发送预设文本 | ✅ 支持 |
| **跳转** | 点击后跳转指定页面 | ❌ 需真机 |
| **事件** | 点击后触发事件 | ❌ 需真机 |

### 快捷指令配置

```json
{
  "quick_commands": [
    {
      "text": "查询天气",
      "icon": "weather_icon",
      "type": "text",
      "content": "今天北京的天气怎么样？"
    },
    {
      "text": "我的订单",
      "icon": "order_icon",
      "type": "text",
      "content": "查询我的最近订单"
    },
    {
      "text": "呼叫客服",
      "icon": "service_icon",
      "type": "text",
      "content": "转人工客服"
    }
  ]
}
```

### 动态快捷指令

动态快捷指令支持通过执行配置的工作流，在不同场景下动态生成不同的快捷指令：

```json
{
  "dynamic_directive": {
    "workflow_id": "dynamic_commands_workflow",
    "event_input": {
      "header": {
        "name": "HalfScreen",
        "namespace": "System"
      },
      "payload": {
        "timeZone": "GMT+08:00",
        "time": "2026-04-16 10:00:00"
      }
    }
  }
}

// 工作流输出格式
{
  "dynamicDirective": [
    {
      "content": "总结摘要",
      "query": "帮我进行总结摘要"
    },
    {
      "content": "一起跳舞",
      "query": "跟我一起来跳舞"
    }
  ],
  "eventInfo": {
    "directiveName": "QuickChips",
    "eventName": "HalfScreen"
  }
}
```

> **注意**：动态快捷指令的工作流开始节点需包含 `EVENT_INPUT` 字段，结束节点需包含 `dynamicDirective`、`eventInfo` 字段。

### 版本和设备控制

快捷指令支持自定义版本和设备，精确控制指令的可见范围：

```json
{
  "visibility": {
    "devices": ["phone", "tablet"],
    "min_version": "11.3.8.300",
    "max_version": "12.0.0.0"
  }
}
```

## 输入文件设置

### 启用文件输入

与智能体对话时，除了发送文本，还可以通过【输入文件设置】勾选图片或文件。勾选后，对话时点击输入框右侧【+】，可发送图片或文件：

```python
# 输入文件设置配置
input_file_config = {
    "photo": {
        "enabled": True,
        "max_count": 9,        # 最多选择9张
        "max_size": "20MB"     # 单张最大20MB
    },
    "file": {
        "enabled": True,
        "max_count": 1,        # 最多选择1个文件
        "max_size": "100MB",   # 单个文件最大100MB
        "formats": ["pdf", "doc", "txt", "xlsx"]
    }
}
```

### 文件类型支持

| 文件类型 | 支持格式 | 大小限制 |
|---------|---------|---------|
| **照片** | JPG、PNG、WEBP、GIF、BMP | 单张最大20MB，最多9张 |
| **文件** | PDF、DOC、DOCX、TXT、XLS、XLSX、PPT、PPTX | 单个最大100MB，每次1个 |

## A2A输出设置

对于 **A2A 模式**的智能体，可以通过【A2A输出设置】绑定卡片输出，最多可添加20条：

```json
{
  "a2a_output": [
    {
      "cardName": "weather_card",
      "description": "天气信息展示卡片",
      "parameters": {
        "cardData": {
          "type": "Object",
          "properties": {
            "city": {"type": "string"},
            "temperature": {"type": "string"},
            "humidity": {"type": "string"}
          }
        }
      }
    }
  ]
}
```

> **注意**：输出参数默认必须包含参数名为 `cardData`、类型为 `Object` 的参数，并且必须添加子项。

## 界面自定义最佳实践

### 1. 风格一致性

```python
# 主题配置示例
theme_config = {
    "style": "nature",           # 自然/科技/温馨
    "background": "forest.jpg",  # 匹配主题的背景
    "voice": "warm_male",        # 匹配主题的音色

}
```

保持智能体的视觉风格、声音风格和语言风格**高度一致**，能显著提升用户对智能体的信任感。

### 2. 快捷指令策略

```python
# 快捷指令设计策略
quick_command_strategy = {
    "principles": [
        "高频操作优先：将用户最常用的功能排在前面",
        "一屏可见：快捷指令数量控制在5-7条",
        "动态优先：利用动态快捷指令实现场景化推荐",
        "清晰表达：文案控制在10个字以内"
    ]
}
```

### 3. 文件输入安全的考虑

```python
# 文件上传安全校验示例
def validate_upload_file(file_info: dict) -> bool:
    """验证上传文件的安全性"""
    allowed_formats = ["jpg", "png", "pdf", "doc", "txt"]
    max_size_mb = 100
    
    file_format = file_info.get("format", "").lower()
    file_size = file_info.get("size_mb", 0)
    
    if file_format not in allowed_formats:
        print(f"不支持的文件格式: {file_format}")
        return False
    
    if file_size > max_size_mb:
        print(f"文件过大: {file_size}MB > {max_size_mb}MB")
        return False
    
    return True
```

## 常见问题（FAQ）

### Q1：背景图片上传后不显示怎么办？

**答**：请检查图片格式是否支持（JPG、PNG、WEBP），图片大小是否超标（建议不超过5MB），以及是否正确选择了竖屏/宽屏模式。

### Q2：角色声音和开场语之间存在延迟吗？

**答**：角色声音在用户首次进入智能体时会被加载，会有短暂缓存时间。建议开场语尽量简洁，避免过长导致用户等待。

### Q3：动态快捷指令没有生效？

**答**：请检查：1）工作流开始节点是否包含 `EVENT_INPUT` 字段；2）结束节点是否包含 `dynamicDirective` 和 `eventInfo` 字段；3）智能体已发布到真机（预览区不支持动态快捷指令）。

### Q4：预置问题可以设置多少个？

**答**：每个智能体最多可设置3个预置问题。建议选择最能代表智能体核心功能的典型问题。

### Q5：如何让用户无法切换音色？

**答**：在角色声音配置中，关闭【终端用户可以切换声音】开关即可。

本文全面介绍了鸿蒙智能体平台的界面自定义功能：

1. **背景图片**：对话态和通话态的双态背景配置，支持视频和首帧
2. **角色声音**：音色选择与用户切换控制
3. **开场对话**：引导用户了解智能体的首屏体验
4. **快捷指令**：预设对话入口和动态生成能力
5. **输入文件设置**：照片和文件上传的精细控制
6. **A2A输出设置**：卡片输出的绑定配置
7. **最佳实践**：风格一致、快捷键策略、多场景适配

界面自定义是提升智能体用户体验的重要环节，精细打磨每个细节能让你的智能体在众多应用中脱颖而出。
