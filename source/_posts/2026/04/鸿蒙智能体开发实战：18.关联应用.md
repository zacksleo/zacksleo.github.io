# 鸿蒙智能体开发实战：关联应用

## 前言

智能体开发完成后，如何让用户在实际的 App 中使用它？**关联应用**功能实现了智能体与鸿蒙原生应用的深度集成——用户无需打开小艺 App，直接在自己常用的应用中就能唤起智能体。本文将详细介绍关联应用的全流程：从 AppGallery Connect 配置、签名设置、AgentKit 集成到真机调试与发布。

## 关联应用概述

### 功能介绍

关联应用是指智能体与鸿蒙应用关联，支持在应用中**一键呼出智能体**。当用户在应用内点击特定组件时，智能体以半屏态呈现，用户可与智能体对话完成各项操作。

> **使用场景**：电商应用中点击"智能客服"图标呼出客服智能体、旅行应用中点击"旅行助手"图标呼出行程规划智能体。

### 效果示例

用户打开应用 APP，点击"组件图标"，即可呼出**半屏态**智能体进行使用，实现无缝的跨应用体验。

## 前提条件

在开始关联应用之前，需要完成以下准备工作：

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | **注册鸿蒙应用** | 已在 AppGallery Connect 创建了鸿蒙应用 |
| 2 | **配置签名** | 已为鸿蒙应用配置手动签名 |
| 3 | **创建智能体** | 已在小艺开放平台创建智能体 |
| 4 | **集成 AgentKit** | 应用 APP 端已集成 AgentKit 能力 |

## 开发步骤

### 步骤一：注册鸿蒙应用

在 AppGallery Connect 中创建鸿蒙应用：

```bash
# 访问 AppGallery Connect
# 1. 登录华为开发者联盟
# 2. 进入"我的应用" -> "创建应用"
# 3. 填写应用名称、包名等信息
# 4. 确认应用分类和语言
# 5. 创建完成后获取应用的 AppID
```

> **参考文档**：[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)、[创建鸿蒙应用指导](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-app-0000002247955506)

### 步骤二：配置签名

使用**手动签名方式**对 HAP 进行签名，如果未签名则无法真机调试：

```json
{
  "signing_config": {
    "mode": "manual",
    "certificate": {
      "type": "p12",              // 证书文件格式
      "file": "keystore.p12",     // 签名证书文件
      "password": "***"           // 证书密码
    },
    "profile": {
      "type": "p7b",              // 配置文件格式
      "file": "profile.p7b"       // 调试/发布配置文件
    }
  }
}
```

> **重要**：使用自动签名方式时，应用运行时的 appid 是随机生成的，与智能体关联应用中配置的 appid 不一致，会导致授权异常。因此**必须使用手动签名方式**。

### 步骤三：创建智能体并关联应用

在智能体编排页中关联应用：

```python
# 关联应用配置
app_association = {
    "agent": "我的智能体",
    "allowed_apps": [
        {
            "app_name": "我的商城",
            "package_name": "com.example.mall",
            "app_id": "123456789",
            "associated": True  # 打开关联开关
        }
    ]
}
```

具体操作步骤：

1. 在智能体编排页点击**关联应用**右侧的【添加】按钮
2. 从应用列表中选择目标应用
3. 打开"是否关联应用"开关

> **注意**：仅支持选择此账号在 AppGallery Connect 中**已上架**的应用。此处配置限制了当前智能体允许在哪些应用 APP 中被拉起。

### 步骤四：应用 APP 集成 AgentKit 能力

AgentKit 是华为提供的鸿蒙原生框架，用于在应用中集成智能体拉起能力：

```typescript
// 通过 Function 组件拉起智能体
import { AgentFunction } from '@hms/agent-kit';

@Component
struct AgentLauncher {
    build() {
        Button('智能助手')
            .onClick(() => {
                // 通过 Function 组件拉起智能体
                AgentFunction.start({
                    agentId: 'your_agent_id',  // 智能体ID
                    sessionId: 'user_session', // 用户会话
                    extraParams: {
                        source: 'mall_app'
                    }
                });
            })
    }
}
```

> **参考文档**：[通过 Function 组件拉起智能体指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/harmony-agent-framework-kit-guide)、[API 参考](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/harmony-agent-framework-api)

### 完整的集成示例

```typescript
// AgentKit 完整集成示例
import { AgentFunction, AgentConfig } from '@hms/agent-kit';

@Entry
@Component
struct MallPage {
    private agentConfig: AgentConfig = {
        agentId: 'your_agent_id',
        scene: 'mall_assistant',
        onResult: (result) => {
            console.info('Agent result:', JSON.stringify(result));
        }
    };

    build() {
        Column() {
            // 商品列表
            List() {
                ForEach(this.products, (product) => {
                    ProductCard({ product: product })
                })
            }
            
            // 悬浮智能体入口
            Stack() {
                Image('agent_icon.png')
                    .width(48)
                    .height(48)
                    .onClick(() => {
                        this.launchAgent();
                    })
            }
            .position({ bottom: 20, right: 20 })
        }
    }
    
    launchAgent() {
        AgentFunction.start(this.agentConfig);
    }
}
```

## 调试及发布

### 调试步骤

开发工作完成后，需要进行真机调试：

1. **调试设备（手机）已登录华为账号**，并且处于联网状态
2. **智能体已发真机测试**到调试设备
3. **打开应用 APP**，点击"组件图标"，即可呼出半屏态智能体

```bash
# 真机测试发布流程
1. 在小艺开放平台将智能体发布为"真机测试"状态
2. 添加测试设备的华为账号到白名单
3. 确保设备的小艺 APP 版本 >= 11.3.8.300
4. 在测试设备上打开目标应用
5. 点击组件图标，验证智能体是否能正常唤起
```

### 调试效果

成功集成后，用户打开应用 APP，点击预设的组件入口，即可看到智能体以**半屏态**呈现，并可与智能体进行对话交互。

## 常见问题（FAQ）

### 问题1：应用中点击"组件图标"时，显示"智能体未授权给该应用"？

**可能原因**：

1. **未配置关联关系**：小艺开放平台未配置目标智能体与目标应用的关联关系，请在平台配置后重新发布智能体调试
2. **信息不一致**：智能体关联应用中配置的应用名称、应用包名、appid 与目标应用实际值不一致，请修改后重试
3. **签名方式错误**：对 HAP 进行签名时使用了**自动签名方式**，此方式下应用运行时的 appid 是随机生成的，与智能体关联应用中配置的 appid 不一致，导致授权异常；请修改为**手动签名方式**后重试

### 问题2：智能体已发真机测试，但目标应用中无"组件图标"？

**可能原因**：

1. **未集成 AgentKit**：应用 APP 未集成 AgentKit 能力，请集成后重新调试
2. **ROM 版本或 API 版本低**：
   - ROM 版本需 **6.0.0** 及以上（通过手机设置-关于本机-软件版本查看）
   - API SDK 需 **20** 及以上（通过手机设置-关于本机-API 版本查看）

### 问题3：目标智能体上架发布后，应用中仍呼出"开发中"（真机测试）智能体？

**答**：智能体已发布，但对于真机白名单中的设备，会**优先拉起"开发中"（真机测试）智能体**。可通过删除真机白名单配置或取消真机发布解决。

### 问题4：目标智能体发布真机测试后，小艺 APP 中有"开发中"智能体，但应用中点击组件图标呼不出来？

**答**：小艺 APP 版本号过低，需 **11.3.8.300** 及以上版本（通过小艺-头像-设置-关于查看小艺版本号）。

## AgentKit 架构解析

### AgentKit 核心组件

AgentKit 是华为提供的鸿蒙原生框架，其架构包含以下核心组件：

| 组件 | 说明 |
|------|------|
| **AgentFunction** | 核心拉起组件，负责启动智能体会话 |
| **AgentConfig** | 配置对象，定义智能体ID、场景、回调等参数 |
| **SessionManager** | 会话管理器，管理用户会话生命周期 |
| **CallbackHandler** | 回调处理器，处理智能体返回结果 |

### AgentKit 生命周期

```typescript
// AgentKit 生命周期管理
class AgentLifecycle {
    // 1. 初始化
    async initialize(config: AgentConfig): Promise<void> {
        console.info('AgentKit 初始化中...');
    }

    // 2. 拉起智能体
    async launchAgent(agentId: string): Promise<void> {
        console.info('拉起智能体:', agentId);
        await AgentFunction.start({ agentId });
    }

    // 3. 处理智能体结果
    handleResult(result: AgentResult): void {
        const { status, data } = result;
        switch (status) {
            case 'completed':
                console.info('任务完成:', data);
                break;
            case 'error':
                console.error('任务出错:', data.message);
                break;
            case 'cancelled':
                console.info('用户取消任务');
                break;
        }
    }

    // 4. 销毁释放
    destroy(): void {
        console.info('AgentKit 资源释放');
    }
}
```
