# 鸿蒙智能体开发实战：大模型算法备案和登记

## 前言

随着《生成式人工智能服务管理暂行办法》等法规的实施，AI产品的合规性已成为上架运营的必要前提。对于鸿蒙智能体开发者来说，**大模型算法备案**和**生成式AI服务登记**是将智能体上架到华为市场的必经之路。

> 合规不是阻碍，而是保障。完成备案登记的智能体能获得用户和平台的信任，同时也是对开发者自身权益的保护。

本文将详细介绍大模型算法备案和生成式AI服务登记的完整流程，以及智能体上架审核中涉及的内容标识、信息规范等合规要求。

## 智能体上架合规总览

### 上架需要完成的两项备案

智能体上架前，开发者需要完成以下两项备案工作：

| 备案类型 | 负责部门 | 适用场景 | 办理周期 |
|---------|---------|---------|---------|
| **生成式AI服务备案登记** | 省级网信办 | 所有使用生成式AI技术的智能体 | 视地方政策而定 |
| **算法备案** | 国家网信办 | 使用非平台提供的大模型 | 视平台流程而定 |

### 两条备案路径

```plaintext
路径一：使用小艺开放平台提供的大模型
  → 大模型备案信息选择"否"
  → 仅需完成生成式AI服务登记（或备案）

路径二：使用第三方（非平台提供）的大模型
  → 大模型备案信息选择"是"
  → 需要提供生成式AI服务上线备案号
  → 需要提供算法备案号
```

## 一、生成式人工智能服务备案登记

### 法律法规依据

根据 **[《生成式人工智能服务管理暂行办法》](https://www.zjwx.gov.cn/col/col1228998798/art/2026/art_c6beabcefb7c43a3bd1bdab925175f6c.html)** 要求，提供生成式AI服务的应用需要进行备案登记。

### 各地政策差异

不同省份的政策要求有所不同，以浙江省为例：

> 对于通过API接口或其他方式直接调用已备案大模型能力的生成式AI应用，经浙江省网信办同意，采用**登记方式**，允许上线提供服务。

**其他地区参考**：

| 地区 | 政策特点 | 备注 |
|------|---------|------|
| 浙江 | 登记制，流程简便 | 调用已备案模型只需登记 |
| 北京 | 备案制，要求较严 | 可能需要提交详细材料 |
| 上海 | 备案+登记并行 | 视具体服务类型而定 |
| 广东 | 分类管理 | 区分基础模型和应用层 |

### 备案登记步骤

```bash
# 办理流程
1. 确认所在地省网信办的备案要求
2. 准备备案材料（主体信息、服务说明、安全评估等）
3. 在线提交备案申请
4. 等待审核（通常5-20个工作日）
5. 获取备案编号
6. 在应用详情页公示备案信息
```

### 备案所需材料

**常见材料清单：**

```markdown
1. **主体信息**
   - 企业营业执照/个人身份证明
   - 联系人及联系方式
   - 服务提供者基本信息

2. **服务信息**
   - 服务名称和功能描述
   - 所使用的大模型信息
   - 服务使用条款

3. **安全评估**
   - 算法安全自评估报告
   - 内容安全措施说明
   - 数据安全保护方案

4. **合规承诺**
   - 合规运营承诺书
   - AI生成内容标识方案
```

## 二、算法备案

### 什么是算法备案

算法备案是指对使用人工智能算法的服务进行登记备案，确保算法的透明度和可解释性，防止算法歧视、算法滥用等问题。

### 谁需要算法备案

根据规定，以下情况需要进行算法备案：

- **使用非平台提供的第三方大模型**
- 自行训练或微调的大模型
- 具有个性化推荐、排序、筛选等功能的算法

### 算法备案流程

```python
# 算法备案流程示意
def algorithm_filing_flow():
    """算法备案流程"""
    steps = [
        ("1. 确认备案类型", "判断属于哪种算法备案类别"),
        ("2. 登录备案系统", "访问 https://beian.cac.gov.cn"),
        ("3. 填写备案信息", "包括算法名称、类型、应用场景等"),
        ("4. 提交安全评估", "算法安全自评估报告"),
        ("5. 等待审核", "审核周期视情况而定"),
        ("6. 获取备案编号", "在系统中查询备案结果"),

    ]
    for step, desc in steps:
        print(f"{step}：{desc}")
```

## 三、人工智能生成合成内容标识

### 标识要求依据

根据 **[《人工智能生成合成内容标识办法》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F32EA2A561F1886CD8D606513512D547)**，利用人工智能技术生成、合成的文本、图片、音频、视频、虚拟场景等信息，需要进行内容标识。

### 标识类型

| 标识类型 | 定义 | 示例 |
|---------|------|------|
| **显式标识** | 以文字、声音、图形等方式呈现，可被用户明显感知 | 文字标注"AI生成"、水印标记 |
| **隐式标识** | 在文件数据中添加技术措施，不易被用户感知 | 元数据标记、数字水印 |

### 如何在智能体中配置AI标识

在智能体上架申请中，需要填写AI生成内容标识信息：

```yaml
# AI生成合成内容标识配置
ai_content_label:
  contains_ai_generated: true  # 是否包含AI生成内容

  # 显式标识方式
  explicit_label:
    text: "AI生成"  # 文字标识
    position: "内容末尾"  # 标识位置
    format: "【AI生成】"

  # 隐式标识方式
  implicit_label:
    watermark_type: "digital"  # 数字水印
    metadata_tag: true  # 元数据标记
```

### 标识自验证方法

开发者可以使用 **AI标识服务检测平台** 验证生成内容是否已正确添加AI标识：

```bash
# AI标识检测步骤
1. 登录 https://www.gcmark.com/web/index.html#/mark/check/image
2. 选择对应类型的标识检测（文本/图片/音频/视频）
3. 上传待检测的文件
4. 点击"开始检测"
5. 查看检测结果
```

### 标识FAQ

**Q: 我的智能体是否包含AI生成合成内容？**

A: 只要智能体使用大模型生成文本、图片、音频等内容，就需要选择"是"，并填写相关标识信息。

**Q: 如何选择标识方式？**

A: 建议同时使用显式标识和隐式标识。显式标识让用户感知内容由AI生成，隐式标识作为技术保障。

**Q: 使用平台API生成的内容，标识由谁负责？**

A: 使用小艺开放平台API生成的内容，平台会自动添加必要标识。但开发者仍需在上架申请中如实说明。

## 四、智能体上架信息规范

智能体上架时，需要填写详细的智能体信息。以下各项均有严格的规范要求。

### 智能体名称

**核心要求：**

| 要求 | 说明 |
|------|------|
| 命名原则 | 直观表达功能、服务或解决的问题 |
| 语言要求 | 简体中文、中英文结合 |
| 禁止内容 | 特殊符号、繁体字、极限词、营销词 |
| 宽泛词限制 | 不得直接使用"北京"、"律师"、"客服"等宽泛词 |
| 名称长度 | 建议简短易记 |

**正确示例：**

> ✅ 智能客服助手
> ✅ 旅游行程规划师
> ✅ 代码审查小助手

**错误示例：**
> ❌ 客服（宽泛通用词）
> ❌ 最智能的助手（极限词）
> ❌ test_agent_v1（包含测试词）

### 智能体头像

**视觉规范：**

- 内容清晰可辨，突出主题
- 需与名称、简介有**关联性**
- 不得使用纯色图片
- 不得包含二维码、联系方式、logo等营销信息
- 图片具备**科技感**，相对年轻化
- 源图必须有版权或为原创

**常见驳回原因：**

```markdown
1. 头像模糊不清（分辨率低、马赛克）
2. 使用纯色或纯色背景+文字组合
3. 包含水印或第三方平台logo
4. 与智能体功能不相关
5. 图片方向错误（镜像、颠倒）
6. 包含含低俗、违规内容
7. 缺乏科技感、与华为品牌调性不符
```

### 智能体描述

**填写规范：**

| 要求 | 说明 |
|------|------|
| 字数限制 | 不超过**50个字** |
| 内容要点 | 介绍功能、服务及特色，言简意赅 |
| 标点符号 | 结尾要有标点符号 |
| 人称统一 | "您"和"你"保持一致，建议统一用"你" |
| 禁止内容 | 广告法禁词、误导词、营销词 |

**正确示例：**
> 专业的旅游行程规划助手，为你定制个性化旅行方案，推荐景点、美食和住宿。

### 智能体开场语

**规范要点：**

- **必填项**，需与功能和内容相关
- 与描述内容**不得重复**
- 建议**69个字以内**（3行以内）
- 使用**细节引导风格**，突出特性优势
- 接地气、有共鸣、写清楚用户价值
- 紧贴**真实使用场景**

**正确示例：**
> 你好！我是你的专属旅行规划师。告诉我你想去哪里、玩几天，我就能为你量身定制一份完美的旅行方案！

### 智能体引导事例

**规范要点：**

- 需为 **1-3条**
- 与智能体优势特性结合
- 建议覆盖**不同场景**
- 主谓宾完整句子，需带标点

**正确示例：**
> • 推荐北京三日游行程
> • 帮我规划一次云南亲子游
> • 周末杭州有什么好玩的？

### 智能体分类

需正确选择**一二级行业分类**，确保与智能体功能匹配。

### 智能体背景图片

背景图片的规范与头像类似，需要满足：

- 内容清晰可辨，突出主题
- 与名称、简介有关联性
- 不得使用纯色图片
- 不得包含二维码、联系方式等
- 具备科技感
- 有版权或原创

### 智能体气泡生成内容

**质量要求：**

- 功能及按钮可用，不得出现闪屏、白屏、闪退
- 生成内容准确、具有权威性
- 保持**时效性**，不得包含过期信息
- 文字通顺、无病句、无错别字
- 段落不得重复，无乱码
- 图文内容可直接预览

### 上架审核FAQ

**Q: 上架审核一般需要多长时间？**

A: 审核周期通常为 **1-3个工作日**。如果材料齐全、合规，审核速度会更快。

**Q: 审核不通过后可以重新提交吗？**

A: 可以。根据审核意见修改问题后重新提交即可。常见问题包括名称不规范、内容合规、AI标识配置不完整等。

**Q: 上架后智能体信息还能修改吗？**

A: 可以。修改信息后需要重新提交审核，审核通过后更新生效。

**Q: 智能体下架的原因有哪些？**

A: 常见原因包括：内容违规被举报、未按要求更新备案信息、存在安全漏洞、侵犯他人权益等。
