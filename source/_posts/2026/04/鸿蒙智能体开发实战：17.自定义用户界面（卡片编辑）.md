# 鸿蒙智能体开发实战：自定义用户界面（卡片编辑）

## 前言

在智能体应用中，除了文本回复外，经常需要展示结构化的交互内容，比如商品展示、订单信息、地图导航等。**自定义卡片编辑器**提供了一套可视化的拖拽式界面设计工具，让开发者无需编写代码即可创建精美的交互式卡片。本文详细介绍自定义卡片编辑器的使用方法，包括组件拖拽、变量绑定、事件配置和完整演示案例。

## 卡片编辑器概述

### 编辑界面布局

自定义卡片编辑页面从左到右分为三个区域：

| 区域 | 功能 | 说明 |
|------|------|------|
| **功能区** | 左侧面板 | 包含可拖拽的组件列表 |
| **预览画布区** | 中间区域 | 实时展示卡片的视觉效果 |
| **属性配置区** | 右侧面板 | 配置选中组件的属性和样式 |

![自定义卡片编辑界面](/images/鸿蒙智能体开发实战/kb-17.1.png)

> 上图展示了自定义卡片编辑器的三区布局：左侧为功能区、中间为预览画布、右侧为属性配置区。

### 基本操作流程

```python
# 卡片创建流程图
card_creation_flow = [
```

## 组件介绍

### 布局组件

布局组件用于组织卡片的整体结构：

| 组件 | 说明 | 使用场景 |
|------|------|---------|
| **行布局** | 将元素横向排列的容器 | 导航栏、标签行 |
| **列布局** | 将元素纵向排列的容器 | 表单、文章列表 |
| **堆叠组件** | 将元素叠放在一起 | 图片上加文字 |
| **动态列表** | 遍历数组生成列表 | 商品列表、订单列表 |
| **滚动容器** | 超出内容可滚动 | 长内容展示 |

### 基础组件

基础组件是构成卡片内容的核心元素：

| 组件 | 说明 | 属性配置 |
|------|------|---------|
| **文本** | 展示文字内容 | 字体大小、粗细、颜色、对齐方式 |
| **图片** | 展示图片 | 尺寸、缩放类型、圆角 |
| **图标** | 展示图标 | 图标标签、大小、颜色 |
| **按钮** | 可点击操作按钮 | 文案、颜色、事件绑定 |
| **标签** | 标记分类信息 | 文本、圆角、颜色 |

## 变量绑定

### 变量类型

卡片可能需要根据场景**动态调整参数**，因此需要创建变量用于在卡片中绑定动态变化的内容。真实的值通过调用时传入：

| 变量类型 | 说明 | 使用场景 |
|---------|------|---------|
| **String** | 字符串 | 文本内容、图片URL |
| **Number** | 数字 | 价格、数量 |
| **Array** | 数组 | 列表数据、选项组 |
| **Object** | 对象 | 复合数据结构 |
| **Object（聚合链接）** | 链接对象 | 跳转链接配置 |
| **Boolean** | 布尔值 | 开关状态、可见性 |

### 创建和绑定变量

```python
# 变量定义示例
variables = {
    "title": "HUAWEI Pura 70 Ultra",        # String
    "price": 9999,                            # Number
    "imageUrl": "https://example.com/phone.png",  # String
    "features": ["卫星通信", "超聚光摄像头"],  # Array
    "product": {                               # Object
        "name": "HUAWEI Pura 70 Ultra",
        "price": 9999,
        "color": "黑色"
    }
}
```

> **绑定规则**：为文本组件绑定变量时，无法绑定数组变量和对象变量；为图片组件绑定变量时，只能绑定字符串类型（图片URL）。

### 变量在画布中的应用

新建变量后，在内容区点击文本内容的右侧按钮，选择变量绑定：

```html
<!-- 变量绑定的效果 -->
<!-- 静态文本 -->
<Text>商品名称</Text>

<!-- 动态文本（绑定变量后） -->
<Text>{{title}}</Text>
<!-- 渲染结果：HUAWEI Pura 70 Ultra -->
```

右侧属性配置栏中，文本内容中的**蓝色字体**表示引用的变量名称。

## 事件配置

### 事件概述

事件功能使卡片具备**交互能力**，例如给按钮设置点击事件，触发点击后跳转到某个应用。

### 事件触发方式

| 触发方式 | 说明 |
|---------|------|
| **点击时** | 用户点击组件时触发 |
| **加载时** | 卡片加载时自动触发 |

### 执行条件

执行条件为可选项，设置后只有满足条件时触发的事件才能执行：

```python
# 执行条件配置
condition = {
    "left_operand": "前置事件返回值或变量",
    "operator": "==",       # 根据左操作数类型提供不同运算符
    "right_operand": "常量或变量"
}
```

### 11种执行动作

卡片目前支持以下执行动作：

| 动作 | 说明 | 典型场景 |
|------|------|---------|
| **跳转** | 跳转到指定页面/应用 | 点击广告跳转详情页 |
| **给小艺对话或智能体发消息** | 将消息发送给小艺或智能体 | 点击后发起对话 |
| **设置变量值** | 更新指定变量的值 | 切换选项后更新显示 |
| **修改组件属性** | 动态修改组件的样式属性 | 展开/收起详情 |
| **切换页面** | 在多页卡片中切换页面 | 分页浏览 |
| **查询应用安装状态** | 检查某应用是否已安装 | 分享前检查 |
| **调用插件** | 调用已绑定的插件 | 点击执行查询 |
| **复制到剪切板** | 将内容复制到系统剪贴板 | 复制验证码 |
| **预览图片** | 全屏预览图片 | 查看大图 |
| **删除列表数据** | 删除动态列表中的条目 | 删除待办事项 |
| **操作小艺** | 调用小艺的能力 | 语音播报 |

## 完整演示案例：华为商城卡片

### 整体设计

将卡片分为**顶部栏**和**商品栏**上下两部分依次绘制。

### 步骤一：搭建顶部栏框架

1. 选择外层**行布局**（将元素横向排列的容器）
2. 在右侧属性栏中设置水平对齐方式为**两端对齐**
3. 内部嵌套两个行布局（"商城"标签区和"更多"按钮区）

```python
# 顶部栏结构
top_bar = {
    "layout": "row",
    "justify_content": "space_between",
    "children": [
        {
            "type": "row",
            "children": [
                {"type": "image", "src": "{{logo}}", "width": 20},
                {"type": "text", "content": "商城", "font_size": 12, "font_weight": 700}
            ]
        },
        {
            "type": "row",
            "children": [
                {"type": "text", "content": "更多", "font_size": 10, "font_weight": 500},
                {"type": "icon", "name": "向右"}
            ]
        }
    ]
}
```

### 步骤二：样式配置

```css
/* 顶部栏样式参考 */
.logo-image {
    width: 20px;
    aspect-ratio: 1/1;
    object-fit: contain;
}

.store-name {
    font-size: 12px;
    font-weight: 700;
    opacity: 100%;
}

.more-text {
    font-size: 10px;
    font-weight: 500;
    opacity: 60%;
}
```

### 步骤三：商品栏-动态列表

使用**动态列表组件**展示商品列表，绑定数组变量：

```json
{
  "listContent": [
    {
      "button3": "购买",
      "listLeftImage": "https://example.com/phone1.png",
      "listMainTitle": "HUAWEI Pura 70 Ultra",
      "listSubTitle1Sub1": "超聚光伸缩摄像头，超高速风驰闪拍",
      "listSubTitle2Sub1": "新品",
      "listSubTitle2Sub2": "12期0分期利息",
      "listSubTitle3Sub1": "¥9999.0"
    },
    {
      "button3": "购买",
      "listLeftImage": "https://example.com/phone2.png",
      "listMainTitle": "HUAWEI Pura 70",
      "listSubTitle1Sub1": "超高速风驰闪拍，第二代昆仑玻璃",
      "listSubTitle2Sub1": "新品",
      "listSubTitle2Sub2": "12期0分期利息",
      "listSubTitle3Sub1": "¥5999.0"
    }
  ]

```

> **技巧**：动态列表区块的数量与数组长度相同，系统自动遍历数组并绘制列表。每个区块中的图片会自动根据数组中的对应字段生成不同的图片。

### 步骤四：地图组件配置

当需要展示地理位置时，可以使用地图组件：

```python
# 地图组件配置
map_config = {
    "locations": {
        "mode": "bind_variable",  # 固定个数 / 绑定变量
        "variable": "locations",
        "show_location_names": True,
        "user_location": True     # 显示用户实时定位
    },
    "route": {
        "enabled": False,
        "variable": "route_data"
    }
}

# 地点数据格式
location_data = [
    {
        "name": "深圳华为基地",
        "latitude": 22.657,
        "longitude": 114.069,
        "thumbnail": "https://example.com/pin.png"
    },
    {
        "name": "北京华为研究所",
        "latitude": 39.908,
        "longitude": 116.397,
        "thumbnail": "https://example.com/pin.png"
    }
]

# 路线数据格式
route_data = [
    {
        "status": 1,  # 0=灰色,1=绿色,2=黄色,3=红色,4=深红色
        "polyline": [
            {"latitude": 22.657, "longitude": 114.069},
            {"latitude": 22.700, "longitude": 114.100},
            {"latitude": 22.750, "longitude": 114.150}
        ]
    }
]
```

### 步骤五：选项组组件配置

选项组（DualSelect）支持单选和多选模式：

```json
{
  "dual_select": {
    "type": "single",       // single / multiple
    "orientation": "horizontal",  // horizontal / vertical
    "options": [
      {"label": "大熊猫", "value": "熊科", "selected": true},
      {"label": "东北虎", "value": "猫科", "selected": false},
      {"label": "金丝猴", "value": "猴科", "selected": false}
    ],
    "interactive": true
  }
}
```

> **事件联动**：当选项变化时，可以设置变量值事件，将选中选项的值赋值给文本组件，实现动态显示效果。

## 卡片预览、保存与发布

### 预览

点击预览后，可在弹出的窗口中预览卡片效果。Web预览展示了卡片在设备上的预期显示效果。

### 保存与发布

预览效果符合预期后，点击**保存并发布**卡片。卡片发布后，在智能体、插件和工作流绑卡时，就可以关联到已发布的卡片。

```python
# 卡片发布流程
card_publish_flow = [
    "1. 完成组件配置和变量绑定",
    "2. 添加事件交互",
    "3. 点击【预览】查看效果",
    "4. 确认无误后点击【保存并发布】",
    "5. 卡片状态变为已发布",
    "6. 在插件/工作流绑卡时选择该卡片"
]
```

## 常见问题（FAQ）

### Q1：动态列表组件绑定了数组变量但列表未显示？

**答**：请检查：1）数组变量是否正确创建并赋值；2）绑定路径是否正确；3）数组中的字段名是否与组件绑定的字段匹配。

### Q2：事件触发了但未执行预期动作？

**答**：请检查：1）执行条件是否满足；2）变量引用是否正确；3）动作参数是否完整。可在预览模式下逐一排查。

### Q3：卡片已发布但无法在插件绑卡时找到？

**答**：请检查卡片是否已完成发布状态。发布后的卡片在绑卡界面才能被搜索到。

### Q4：地图组件不显示地点？

**答**：请检查：1）地点名称、经纬度是否正确；2）变量格式是否符合规范；3）是否已获取到定位权限（显示用户实时定位时需要）。
