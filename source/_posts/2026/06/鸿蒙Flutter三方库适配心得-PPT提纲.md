## 第 4 页：前置知识 — Flutter 插件的消息路由

**内容：**
- Flutter 插件 = Dart 层 + 原生层，通过 MethodChannel 通信
- channel name 是路由唯一凭据
- HarmonyOS 的 flutter_ohos 完全兼容此机制
- 适配的本质：为鸿蒙注册一个 MethodChannel 处理器

**需要绘制的插图（核心）：**

```
┌─────────────┐
│  Flutter App│  (Dart)
│  ┌────────┐ │
│  │channel │ │
│  │.invoke │ │
│  └───┬────┘ │
└──────┼───────┘
       │ channel name
       ▼
┌─────────────────────┐
│  MethodChannel 路由  │
├──────┬──────┬───────┤
│      │      │       │
│  ▼   │  ▼   │   ▼   │
│Android│ iOS  │ OHOS  │  ← 缺实现
│      │      │  ???  │
└──────┴──────┴───────┘
```

**视觉要点：**
- OHOS 列用虚线/红色标注"缺实现"
- channel name 用粗体 + 引号标注，强调关键性

## 第 11 页：思路二 — 优化方案：壳工程模式

**内容：**
- 纯 Fork 的问题：主工程 android/iOS 用原插件（pub.dev），鸿蒙用 Fork（git），依赖管理混乱
- 壳工程：新建一个独立项目 ohos_app，与主工程解耦

**需要绘制的插图——壳工程架构图：**

```
monorepo/
├── apps/
│   ├── app/              ← 主工程（Android + iOS）
│   │   └── pubspec.yaml  ← 原版插件 (pub.dev)
│   │
│   └── ohos_app/         ← 壳工程（鸿蒙适配）
│       ├── lib/          ← 仅入口
│       ├── ohos/         ← 鸿蒙原生代码
│       └── pubspec_overrides.yaml  ← 🔑 覆盖 Fork 插件
│
└── common/               ← 公共模块，被两个 app 共享
    ├── domains/
    ├── services/
    └── widgets/
```

**代码框：**
```yaml
# ohos_app/pubspec_overrides.yaml
path_provider:
  git:
    url: "https://openharmony-sig/...git"
    path: "packages/path_provider/path_provider"
```

**对比表格：**

| 维度 | 直接 Fork | 壳工程模式 |
|------|----------|-----------|
| 主工程 | 可能受影响 | 完全隔离 |
| Android/iOS 构建 | 可能污染 lock | 独立 lock |
| 版本管理 | 混在一起 | 独立版本号 |

## 第 16 页：思路四 — 联合插件理念（架构图）

**内容：**
- 大部分插件是普通插件（非联合架构）
- 借鉴联合插件思路，创建纯 ohos 包
- 包内无 Dart 代码，只有 ArkTS 原生实现
- 用相同 channel name 拦截 MethodChannel 调用

**需要绘制的插图——消息路由图（核心）：**

```
Flutter App
  │
  ├─ import 'app_set_id'
  │     └─ MethodChannel('app_set_id').invoke('getIdentifier')
  │                              │
  │                              ▼
  │                    MethodChannel 路由
  │                    ┌────┬────┬────┐
  │                    │And │iOS │OHOS│
  │                    └────┴────┴─▲──┘
  │                               │
  └─ app_set_id_ohos ─────────────┘
     (ArkTS, 无 Dart 代码)
     new MethodChannel('app_set_id')  ← 同名 channel
```

**视觉要点：**
- 粗箭头突出路由到 OHOS 的路径
- 标注"无 Dart 代码，只有 ArkTS"
- 高亮 channel name 一致性

## 附录：PPT 风格建议

| 要素 | 建议 |
|------|------|
| **主色调** | Flutter 蓝 (#02569B) + 鸿蒙红 (#E31728) 渐变 |
| **字体** | 标题：思源黑体 Bold / 正文：思源黑体 Regular |
| **代码字体** | JetBrains Mono 或 Cascadia Code |
| **插图风格** | 扁平化，圆角矩形，避免 3D |
| **每页文字** | 不超过 7 行，每行不超过 15 字 |
| **代码块** | 浅色背景 + 边框，不超过 5 行 |
