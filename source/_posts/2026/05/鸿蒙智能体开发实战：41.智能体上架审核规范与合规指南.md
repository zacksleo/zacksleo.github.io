## 前言

智能体开发完成后的**上架审核**是迈向用户的关键一步。小艺开放平台对上架智能体有严格的审核规范，涵盖**智能体信息、安全、功能、内容、付费、广告、隐私、未成年人保护、知识产权**等多个维度。了解并遵循这些规范，是智能体顺利通过审核、成功上架的**必要条件**。

本文是 **「鸿蒙智能体开发实战」** 系列的第四十一篇，将全面梳理小艺开放平台的上架审核规范，帮助开发者在提交审核前完成**自查自检**，大幅提升审核通过率。

> **上架审核**是智能体**合规运营**的基石。一次通过审核，可以节省大量的迭代时间。建议在开发初期就参考本文的规范进行设计。

## 一、智能体信息规范

### 1.1 智能体名称

名称是用户对智能体的**第一印象**，审核规范对名称有严格的要求：

| 审核维度 | 要求说明 | 合规示例 | 不合规示例 |
|---------|---------|---------|-----------|
| **功能表达** | 需直观表达智能体的功能或服务 | 壁纸生成助手 | 小可爱 |
| **语言规范** | 仅支持简体中文或中英文结合 | 今日笑话Joke | Test_Agent_01 |
| **避免营销** | 不得含价格、促销等商业化词汇 | 法律咨询助手 | 9块9法律咨询 |
| **禁止宽泛** | 不得直接使用城市名、行业名等概念性词语 | 北京旅游攻略 | 北京 |
| **禁止夸大** | 不得使用极限性、夸大性词语 | 英语学习伙伴 | 全网第一英语 |
| **禁止侵权** | 需进行商标侵权评估 | 个性化名称 | 华为官方助手 |

名称的**核心原则**：让用户一眼就能知道这个智能体能做什么。

### 1.2 智能体头像

头像是智能体的**视觉标识**，审核要求包括：

1. **清晰可辨**：分辨率不低于512x512，不得有花屏、马赛克、锯齿等问题
2. **方向正确**：不可为镜像图、颠倒、扭曲或拉伸
3. **避免纯色**：不得使用纯色图片或纯色背景+文字组合
4. **无营销元素**：不得含网站水印、二维码、联系方式、社交账号等
5. **无排名暗示**：不得使用"官方"、"权威"、"推荐"、"精品"等词汇
6. **版权原创**：源图必须有版权，不得侵权

> **提示**：智能体头像需具备**科技感**、**年轻化**，且需与智能体功能匹配。建议使用体现AI智能体特性的设计风格。

### 1.3 智能体描述与开场语

**智能体描述**是展示在智能体卡片上的简短介绍，要求如下：

- 与名称、头像功能相关，描述和开场语不得重复
- 总字数不超过**50个字**
- 不得含广告法禁用词汇（"最"、"第一"、"绝对"等）
- 不得含联系方式、社交账号等诱导内容

**开场语**是用户进入智能体后看到的**第一句话**：

```
✅ 合规示例：
"你好！我是壁纸大师，告诉我你喜欢的风格，我为你生成专属壁纸～"

❌ 不合规示例：
"欢迎使用本智能体，它可以帮助你做很多事情，功能非常强大..."
```

开场语的核心要求：**有场景感、有引导性、有温度**，建议控制在69字以内。

## 二、智能体安全规范

智能体安全审核确保智能体不会对用户设备和数据造成危害：

1. **无病毒木马**：不得含可疑代码、文件或程序
2. **无劫持行为**：不得劫持桌面、监听剪切板、设置钓鱼链接
3. **无远程控制**：不得允许攻击者远程控制设备
4. **无资源滥用**：不得在用户不知情下进行挖矿、刷量等行为
5. **无功能干扰**：不得干扰系统功能，如返回键失灵、进程无法停止

## 三、智能体功能规范

### 3.1 功能完整性

智能体需具备**实用价值**，为用户提供实质功能或服务：

- 需适配华为主流终端设备
- 能正常启动和返回，不得频繁崩溃或闪退
- 不得为纯信息展示或简易功能
- 功能需在智能体内闭环实现，不得以使用其他应用为前提

### 3.2 禁止行为

以下行为在功能审核中会被**直接拒绝**：

1. **恶意导流**：以领红包、做任务等名义诱导用户跳转到第三方服务
2. **虚假跳转**：未实现基础功能，诱导用户下载应用
3. **伪装推荐**：伪装成推荐、排行等形式进行推广
4. **流程中断**：强制要求跳转后才能继续使用

> **注意**：智能体不得提供虚假或误导性功能，不得协助用户实施欺骗行为。例如，不得提供生成印章、身份证等违法功能。

## 四、智能体内容规范

### 4.1 内容安全红线

以下是内容审核的**绝对红线**，触碰即被下架：

涉及违法内容的具体类型包括：

1. **违法违规信息**：非法金钱交易、赌博、恐怖行动
2. **色情低俗**：不得含有或传播色情、低俗、性暗示内容
3. **暴力血腥**：不得描绘对人类或动物的杀害、残害
4. **歧视仇恨**：不得有种族、性别、宗教等歧视内容
5. **毒品烟酒**：不得鼓励使用毒品、过量饮酒、吸烟
6. **封建迷信**：不得传播邪教和封建迷信内容
7. **诱导沉迷**：不得利用算法诱导用户沉迷、过度消费

// 内容安全过滤器示例
class ContentModerator {
    constructor() {
        this.blocklist = ['赌博', '色情', '毒品', '暴力', '欺诈'];
    }
    
    moderate(text) {
        const found = this.blocklist.filter(word => text.includes(word));
        if (found.length > 0) {
            return {
                pass: false,
                blocked_words: found,
                action: 'block'
            };
        }
        return { pass: true, action: 'allow' };
    }
}

### 4.2 拟人化限制

根据《人工智能拟人化互动服务管理暂行办法》，平台暂不支持**拟人化类智能体**上架。这意味着智能体不应模仿真人身份（如"虚拟女友"、"虚拟男友"等）。

### 4.3 AI生成内容标识

根据《人工智能生成合成内容标识办法》等法规要求，AI生成的内容需添加**显著标识**，确保用户知悉内容由AI生成。

```python
# AI生成内容标识示例
def add_ai_watermark(content, content_type="text"):
    """为AI生成内容添加标识"""
    watermark_map = {
        "text": "\n\n---\n*本文由AI生成，请注意甄别*",
        "image": "添加AI生成水印到图片右下角",
        "audio": "在音频开头添加语音声明"
    }
    return content + watermark_map.get(content_type, "")
```

## 五、上架资质与备案

### 5.1 大模型备案要求

智能体接入大模型需满足以下备案要求：

| 情况 | 要求 | 补充说明 |
|------|------|---------|
| **未接入大模型** | 可忽略 | 仅使用规则引擎或固定回复 |
| **已接入大模型** | 提供备案号和算法备案编号 | 必须完成生成式AI服务备案 |
| **正在备案中** | 可在3个月内补交 | 临时上架，到期未补交将下架 |

### 5.2 内容合规与AI标识

根据相关法规，智能体需完成以下合规要求：

1. **生成式人工智能服务备案登记**：向属地网信部门提交备案
2. **算法备案**：在互联网信息服务算法备案系统完成备案
3. **AI生成标识**：对AI生成内容添加显著标识

> 文章24（大模型算法备案和登记）已对**算法备案**和**生成式AI备案**的流程做了详细介绍，建议在提交上架审核前仔细阅读。

## 六、智能体付费规范

### 6.1 付费基本原则

如果智能体涉及付费，需遵循以下原则：

- 需根据实际情况选择**免费或付费**类型
- 定价需合理，不得过高或存在价格欺诈
- 付费信息需**清晰明了**，不得误导用户

### 6.2 自动续费服务要求

提供自动续费服务的智能体，需满足以下要求：

1. **显著告知**：开通前在显著位置披露付费信息和价格
2. **用户确认**：支付需用户**二次确认**，不得默认勾选
3. **信息一致**：服务内容与明示内容保持一致
4. **提前提醒**：续期前**5日**内发送有效提醒
5. **便捷退订**：提供单独的退订方式，操作简单

### 6.3 抽奖与概率机制

如涉及付费随机抽取（盲盒、抽奖等），需在支付前显著位置明示：

## 七、智能体广告规范

### 7.1 广告内容要求

智能体内广告需遵守以下要求：

1. **可识别性**：需清晰标注"广告"字样
2. **真实性**：不得含有虚假或引人误解的内容
3. **一致性**：广告链接内容需与前段展示一致
4. **合法性**：需经审查的广告需按审查内容发布

### 7.2 广告展示规范

广告不得影响用户正常使用体验：

1. 不得恶意频繁弹出广告，中断用户操作
2. 不得在用户点击系统功能键时弹出广告
3. 不得在智能体外弹出广告窗口
4. 不得在退出智能体后仍弹出广告

### 7.3 关闭标识要求

广告需提供**一键关闭**功能，且关闭标识需符合以下要求：

- 不得提供虚假或无效的关闭标志
- 关闭标志不得过小或隐蔽
- 不得延迟展示关闭标志或倒计时
- 关闭后不得继续弹出广告

## 八、用户隐私规范

### 8.1 隐私政策

隐私政策是上架审核的**核心要求**：

1. **可便捷查看**：必须在平台或智能体内提供隐私政策链接
2. **内容公开透明**：需与智能体实际数据处理保持一致
3. **覆盖第三方**：需包含委托第三方或嵌入代码的隐私说明
4. **权利说明**：需包含用户如何撤销同意、删除数据的说明

### 8.2 用户同意

收集用户个人信息前，必须遵循以下原则：

1. **知情同意**：以清楚明确的方式呈现隐私政策，获取用户**自愿明确**的同意
2. **单独同意**：处理敏感个人信息需获取用户的单独同意
3. **撤销机制**：提供简单易懂的撤销同意方式
4. **拒绝不影响使用**：用户拒绝非必需信息时，不影响使用基本功能

### 8.3 数据最小化

- 收集和使用个人信息限于实现处理目的的**最小范围**
- 不得暗中收集信息
- 不得超出服务所必需收集信息
- 禁止出售用户个人信息

## 九、未成年人保护

### 9.1 面向未成年人的智能体要求

如果智能体目标受众包含未成年人，需遵守严格的规范：

1. **内容适龄**：所有内容均适合未成年人，不得危害身心健康
2. **防沉迷**：设置时间管理、权限管理、消费管理功能
3. **无诱导**：不得向未成年人提供诱导沉迷的产品或服务
4. **无广告误导**：在线教育类智能体不得含游戏链接或广告

### 9.2 通用要求

即使智能体不面向未成年人，也需注意：

1. 非儿童类智能体信息中不得包含"适合幼儿"、"适合儿童"等暗示
2. 不得包含对未成年人的网络欺凌内容
3. 不得向未成年人宣传烟酒、整容等有害内容

## 十、知识产权规范

### 10.1 版权与授权

智能体内容涉及的知识产权问题：

| 类型 | 要求 | 后果 |
|------|------|------|
| **版权内容** | 使用他人版权内容需事先获得授权 | 下架+法律风险 |
| **破解/汉化** | 不得发布他人版权内容的破解版 | 直接下架 |
| **商标使用** | 未经授权不得使用他人商标 | 商标侵权 |
| **华为标识** | 未经授权不得使用华为商业名称和商标 | 审核不通过 |

### 10.2 合规使用

- 不得销售或推广**仿冒商品**
- 不得侵犯他人肖像权、名誉权
- 不得误导用户认为智能体与华为或其他品牌有特定联系

### 11.2 上架操作

智能体上架分为以下几个步骤：

1. **完成开发**：确保智能体所有功能已开发和测试完成
2. **真机测试**：在华为设备上进行真实环境测试
3. **提交审核**：在平台点击【上架】，填写审核信息
4. **等待审核**：审核周期为**1~3个工作日**
5. **审核结果**：通过则上架成功，不通过则查看审核意见并修改

### 11.2 审核不通过处理

如果审核被驳回：

1. 在【版本记录】中查看审核意见
2. 根据审核意见修改智能体配置
3. 重新提交审核

```python
# 上架审核状态检查
def check_review_status(agent_id):
    """查询智能体审核状态"""
    status_map = {
        "draft": "草稿 - 尚未提交审核",
        "reviewing": "审核中 - 预计1-3个工作日",
        "approved": "已通过 - 智能体已上架",
        "rejected": "不通过 - 请查看审核意见",
        "offline": "已下架 - 需重新提交审核"
    }
    return status_map.get(agent_id, "未知状态")
```

### 11.3 升级与版本管理

1. **版本升级**：已上架智能体可提交升级审核，审核期间线上保留旧版本
2. **版本回退**：支持回退到历史版本
3. **智能体下架**：下架后用户无法使用，可编辑后重新上架

> **提示**：升级审核未通过时，线上依然保留上一次通过审核的版本供用户使用，不会影响线上服务。

## 十二、上架前自检清单

提交上架前，建议逐项检查以下内容：

| 检查项 | 说明 | 状态 |
|-------|------|------|
| **名称合规** | 无极限词、无宽泛词、无营销词 | ☐ |
| **头像合规** | 清晰、无侵权、无营销元素 | ☐ |
| **描述/开场语** | 不重复、不夸大、有引导性 | ☐ |
| **功能完整** | 无崩溃、无闪退、功能可闭环 | ☐ |
| **内容安全** | 无违法信息、无敏感内容 | ☐ |

## 十三、常见问题（FAQ）

### 13.1 审核周期相关问题

**问：智能体审核需要多长时间？**

答：智能体审核周期为 **1~3个工作日**，如果审核不通过会返回审核意见。建议在提交前仔细对照上架审核规范进行自查，提高一次通过率。

### 13.2 审核被驳回相关问题

**问：审核不通过时如何查看原因？**

答：可以通过两种方式查看：1）在智能体编排页面的【版本记录】中查看审核结果；2）在智能体列表页的状态标签上悬浮查看。

**问：审核被驳回后需要重新排队吗？**

答：修改后重新提交会进入新的审核队列，审核周期同样为1~3个工作日。建议在修改完成后充分测试再提交。

### 13.3 大模型备案相关问题

**问：如果还没有完成大模型备案，可以上架吗？**

答：可以。如果已提交备案但还未完成，可以临时上架，但需在**3个月内**补充完成备案编号。到期未补充将被下架。
