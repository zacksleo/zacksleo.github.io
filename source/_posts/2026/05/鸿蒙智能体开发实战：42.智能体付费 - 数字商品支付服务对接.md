## 前言

当智能体需要提供**付费数字商品或服务**（如虚拟会员、游戏道具、点卡充值等）时，需要集成**智能体数字商品支付服务**来实现用户付费和权益发放的商业闭环。华为提供了完整的支付服务配置和接口规范，帮助开发者快速完成商业化部署。

本文是 **「鸿蒙智能体开发实战」** 系列的第四十二篇，详细介绍智能体数字商品支付服务的**配置流程、交互接口、权益管理和订单通知**机制，帮助开发者为智能体接入商业化能力。

> **注意**：智能体数字商品支付服务当前处于**内测阶段**，仅**企业开发者**可用。使用前需通过商务或提华为开发者联盟工单联系小艺商业化运营人员申请开通。

## 一、支付服务概述

### 1.1 服务架构

智能体数字商品支付服务的整体架构包含以下关键角色：

![智能体数字商品支付服务架构](https://blog.shaohushuo.com/images/鸿蒙智能体开发实战/kb-42.1.png)

*上图展示了智能体支付服务的完整数据流：用户发起购买 → 智能体请求支付 → 华为IAP处理 → 订单通知开发者服务器 → 开发者发放权益。*

### 1.2 核心流程

一次完整的付费流程包含以下步骤：

1. **用户发起购买**：用户在小艺应用中点击智能体内的付费商品
2. **支付请求**：智能体向华为IAP（应用内支付）发起支付请求
3. **用户确认支付**：用户通过华为支付完成付款确认
4. **订单通知**：华为支付系统通过**订单通知接口**通知开发者服务器
5. **权益下发**：开发者服务器验证订单后，为用户下发对应的商品权益
6. **权益查询**：用户可以通过**权益查询接口**查看已购买的商品权益

### 1.3 适用商品类型

智能体数字商品支付服务支持以下商品类型：

| 商品类型 | 说明 | 示例 |
|---------|------|------|
| **一次性商品** | 用户付费购买后永久拥有 | 智能体高级皮肤、专属工具包 |
| **时效性商品** | 用户付费购买后在限定时间内使用 | 月度会员、季度订阅 |
| **自动续费商品** | 周期性自动扣费的订阅服务 | 年度VIP自动续费 |
| **消耗性商品** | 使用后消耗，需要重复购买 | 虚拟货币、生成次数 |
| **盲盒/抽奖** | 随机获取不同价值的虚拟道具 | 限定皮肤盲盒 |

## 三、权益查询接口

### 3.1 接口功能

**权益查询接口**用于查询用户在智能体内的权益信息。支持用户查询名下所有已购买的权益，包括权益类型、有效期、剩余次数等。

### 3.2 接口规范

```http
GET /api/v1/entitlements
Host: your-server.com
Authorization: Bearer <access_token>
Content-Type: application/json
```

请求参数说明：

| 参数 | 类型 | 是否必填 | 说明 |
|------|------|---------|------|
| **user_id** | String | 是 | 用户唯一标识 |
| **product_id** | String | 否 | 商品ID，不传则查询所有权益 |
| **status** | String | 否 | 权益状态：active/expired/all |
| **page** | Integer | 否 | 页码，默认1 |
| **page_size** | Integer | 否 | 每页数量，默认20 |

### 3.3 接口实现示例

```python
# 权益查询接口实现
from flask import Flask, request, jsonify
from datetime import datetime, timedelta

app = Flask(__name__)

# 模拟权益数据库
entitlements_db = {}

@app.route("/api/v1/entitlements", methods=["GET"])
def query_entitlements():
    user_id = request.args.get("user_id")
    product_id = request.args.get("product_id")
    status = request.args.get("status", "active")
    
    # 查询用户权益
    user_entitlements = entitlements_db.get(user_id, [])
    
    # 按商品过滤
    if product_id:
        user_entitlements = [
            e for e in user_entitlements 
            if e["product_id"] == product_id
        ]
    
    # 按状态过滤
    now = datetime.utcnow()
    if status == "active":
        user_entitlements = [
            e for e in user_entitlements
            if e["expires_at"] > now.isoformat()
        ]
    elif status == "expired":
        user_entitlements = [
            e for e in user_entitlements
            if e["expires_at"] <= now.isoformat()
        ]
    
    return jsonify({
        "code": 0,
        "message": "success",
        "data": {
            "total": len(user_entitlements),
            "items": user_entitlements
        }
    })

if __name__ == "__main__":
    app.run(port=5000)
```

## 四、订单通知接口

### 4.1 接口功能

**订单通知接口**由华为支付系统调用，用于通知开发者下发或撤销商品权益。在用户完成付款或申请退款后，华为会调用此接口通知开发者执行相应操作。

### 4.2 鉴权方式

订单通知接口支持**非对称密钥认证**：

1. 基于**RSA3072**生成非对称密钥对用于签名认证
2. 开发者在华为开发者联盟网页上下载公钥
3. 私钥由华为侧保管用于签名
4. 公钥供开发者用于验签

> **提示**：非对称密钥认证比AK/SK认证具有更高的安全性，建议在支付场景中优先使用。验签失败时，请检查公钥是否正确配置。

### 4.3 接口实现示例

```python
# 订单通知接口实现
from flask import Flask, request, jsonify
import hashlib
import hmac
import json

app = Flask(__name__)

@app.route("/api/v1/order/notification", methods=["POST"])
def order_notification():
    """接收华为支付系统的订单通知"""
    # 1. 验证签名
    signature = request.headers.get("X-Signature")
    timestamp = request.headers.get("X-Timestamp")
    
    if not verify_signature(request.data, signature, timestamp):
        return jsonify({"code": 401, "message": "signature verification failed"}), 401
    
    # 2. 解析通知数据
    data = request.get_json()
    order_id = data.get("order_id")
    event_type = data.get("event_type")  # grant/revoke
    
    # 3. 处理订单
    if event_type == "grant":
        # 发放权益
        result = grant_entitlement(
            user_id=data["user_id"],
            product_id=data["product_id"],
            order_id=order_id
        )
    elif event_type == "revoke":
        # 撤销权益（退款）
        result = revoke_entitlement(
            user_id=data["user_id"],
            order_id=order_id
        )
    else:
        return jsonify({"code": 400, "message": "unknown event type"}), 400
    
    if result["success"]:
        return jsonify({"code": 0, "message": "success"})
    else:
        return jsonify({"code": 500, "message": result["error"]}), 500

    from datetime import datetime, timedelta
```

## 五、自动续费管理

### 5.1 续费逻辑

自动续费服务的核心逻辑包含以下要点：

1. **续费时机**：在当前周期到期前触发续费
2. **续费提醒**：到期前5日发送续费提醒给用户
3. **续费执行**：用户授权后自动扣费
4. **续费结果**：扣费成功则延长权益，失败则通知用户

```javascript
// 自动续费状态机
const RenewalStateMachine = {
    states: {
        ACTIVE: "active",
        RENEWING: "renewing",
        PAYMENT_FAILED: "payment_failed",
        CANCELLED: "cancelled",
        EXPIRED: "expired"
    },
    
    transitions: {
        active: {
            on_renewal_due: "renewing",
            on_cancel: "cancelled"
        },
        renewing: {
            on_payment_success: "active",
            on_payment_failed: "payment_failed",
            on_cancel: "cancelled"
        },
        payment_failed: {
            on_retry: "renewing",
            on_cancel: "cancelled",
            on_expire: "expired"
        }
    }
};
```

### 5.2 退订处理

用户可以在任意时间退订自动续费服务，退订后：

- 当前周期内权益**继续有效**
- 到期后**不再自动续费**
- 用户可随时重新订阅

## 六、错误处理与重试

### 6.1 接口错误码

权益查询和订单通知接口可能返回以下错误码：

| 错误码 | 说明 | 处理方式 |
|-------|------|---------|
| **0** | 成功 | 正常处理 |
| **401** | 鉴权失败 | 检查签名算法和密钥 |
| **404** | 资源不存在 | 检查请求参数 |
| **429** | 请求频率超限 | 增加重试间隔 |
| **500** | 服务器内部错误 | 联系技术支持 |

### 6.2 重试策略

订单通知接口需要支持**幂等处理**，避免重复通知导致权益重复发放：

```python
def process_order_notification(order_id, event_type, user_id, product_id):
    """幂等处理订单通知"""
    # 检查是否已处理过该订单
    existing = db.query("SELECT status FROM orders WHERE order_id = ?", [order_id])
    
    if existing and existing["status"] == "completed":
        # 已处理，直接返回成功（幂等）
        return {"code": 0, "message": "already processed"}
    
    if event_type == "grant":
        # 发放权益
        grant_entitlement(user_id, product_id, order_id)
    elif event_type == "revoke":
        # 撤销权益
        revoke_entitlement(user_id, order_id)
    
    # 标记订单已处理
    db.execute(
        "INSERT OR REPLACE INTO orders (order_id, status, processed_at) VALUES (?, ?, ?)",
        [order_id, "completed", datetime.utcnow().isoformat()]
    )
    
    return {"code": 0, "message": "success"}
```

## 八、常见问题（FAQ）

### 8.1 开通相关问题

**问：个人开发者可以使用支付服务吗？**

答：目前仅**企业开发者**可用。个人开发者可以通过注册企业账号或联系商务了解开通条件。

**问：支付服务的开通周期是多长？**

答：从提交申请到正式开通一般需要 **1~2周**，包括商务洽谈、技术对接和测试验证。

### 8.2 技术相关问题

**问：订单通知接口没有收到回调怎么办？**

答：请检查接口地址是否正确配置，以及签名验证逻辑是否正常。华为支付系统会自动重试，建议确保接口的**幂等性**。

**问：如何处理用户退款？**

答：当用户申请退款时，华为支付系统会调用订单通知接口（event_type=revoke），开发者收到通知后需在系统中撤销对应权益。

### 8.3 商业化相关问题

**问：智能体内是否可以同时提供免费和付费功能？**

答：可以。建议采用**Freemium**模式，基础功能免费，高级功能付费。但需在智能体描述和场对话中清晰说明免费和付费的范围。

**问：自动续费用户如何管理？**

答：开发者需在智能体内提供**自动续费管理页**，展示用户全部已购买且在有效期内的自动续费服务信息，并支持用户便捷退订。
