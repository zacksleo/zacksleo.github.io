> 背景

正常情况下，使用宝塔创建好网站以后，在设置的配置文件中会有内容，这个就是 Nginx 的配置。
如果发现内容是空的，很有可能无法正常启动 Nnginx

![alt text](https://blog.shaohushuo.com/images/2025/07/23/image.png)

保存时，提示“指定文件不存在”，这也是 Nginx 无法启动的原因。


## 解决方案

### 背景知识

宝塔按照固定的规则，给网站创建对应的配置文件，例如：

假设网站名称为：example.com，则对应创建的配置文件为：

`/www/server/panel/vhost/nginx/example.com.conf`

### 查找配置文件

所以我们使用文件管理，打开目录 `/www/server/panel/vhost/nginx/`，发现并没有这样的文件，那么我们就需要创建这个文件。

### 创建配置文件

我们点击“新建”，“新建空白文本”，然后将这个文件名称改为 example.com.conf

### 配置

回到网站管理的配置页面，这里就可以继续编辑了。我们可以从其他网站的配置中，找一个将配置复制过来：

```lua
server
{
    listen 80;
    server_name example.com;
    index index.php index.html index.htm default.php default.htm default.html;
    root /www/wwwroot/example.com;
    #CERT-APPLY-CHECK--START
    # 用于SSL证书申请时的文件验证相关配置 -- 请勿删除
    include /www/server/panel/vhost/nginx/well-known/1example.com.conf;
    #CERT-APPLY-CHECK--END

    #SSL-START SSL相关配置，请勿删除或修改下一行带注释的404规则
    #error_page 404/404.html;
    #SSL-END

    #ERROR-PAGE-START  错误页配置，可以注释、删除或修改
    error_page 404 /404.html;
    #error_page 502 /502.html;
    #ERROR-PAGE-END

    #PHP-INFO-START  PHP引用配置，可以注释或修改
    include enable-php-00.conf;
    #PHP-INFO-END

    #REWRITE-START URL重写规则引用,修改后将导致面板设置的伪静态规则失效
    include /www/server/panel/vhost/rewrite/example.com.conf;
    #REWRITE-END

    #禁止访问的文件或目录
    location ~ ^/(\.user.ini|\.htaccess|\.git|\.env|\.svn|\.project|LICENSE|README.md)
    {
        return 404;
    }

    #一键申请SSL证书验证目录相关设置
    location ~ \.well-known{
        allow all;
    }

    #禁止在证书验证目录放入敏感文件
    if ( $uri ~ "^/\.well-known/.*\.(php|jsp|py|js|css|lua|ts|go|zip|tar\.gz|rar|7z|sql|bak)$" ) {
        return 403;
    }

    location ~ .*\.(gif|jpg|jpeg|png|bmp|swf)$
    {
        expires      30d;
        error_log /dev/null;
        access_log /dev/null;
    }

    location ~ .*\.(js|css)?$
    {
        expires      12h;
        error_log /dev/null;
        access_log /dev/null;
    }
    access_log  /www/wwwlogs/example.com.log;
    error_log  /www/wwwlogs/example.com.error.log;
}
```

### 编辑

复制过来以后，我们修改上面的内容，将所有 example.com 替换为网站自己的名（网站列表中第一列的名字）。


点击保存，之后网站就可以正常启动了。
