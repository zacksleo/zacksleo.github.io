## 背景

宝塔创建网站以后，在网站配置中，会有内容，这个就是 Nginx/Apache 的配置。

同时还有一个伪静态配置，这个也是 Nginx/Apache 的配置。那么两者有什么区别呢？

本文以 Nginx 为例，介绍两者的关系。

## 原理

实际上这两个都是 nginx 的配置文件，观察设置里面配置的内容，有这么几行配置内容：

```lua
    #REWRITE-START URL重写规则引用,修改后将导致面板设置的伪静态规则失效
    include /www/server/panel/vhost/rewrite/example.com.conf;
    #REWRITE-END
```

这意思是说，配置文件包含了伪静态这个配置文件，相当于引入进来。而文件 `/www/server/panel/vhost/rewrite/example.com.conf`
则是伪静态的对应配置文件。

这些我们可以在设置好伪静态以后，在文件中打开这个路径查看，发现就是伪伪静态处设置的内容。

## 技巧

那么，经过上面的分析，我们可以发现，伪静态中不仅可以设置常见的伪静态规则，也可以添加自己的自定义规则。

### 路径重写

举个例子，我们需要添加一条转发规则


```lua
location /wsm/ {
    root /usr/share/nginx/html;
    index index.html index.htm;
    try_files $uri $uri/ @router; #需要指向下面的@router否则会出现vue的路由在nginx中刷新出现404
}

# 对应上面的@router，主要原因是路由的路径资源并不是一个真实的路径，所以无法找到具体的文件
# 因此需要rewrite到index.html中，然后交给路由在处理请求资源
location @router {
    rewrite ^.*$ /index.html last;
}
```

在上面的配置中，我们添加了一个 location，这个 location 的作用是，当访问 `/wsm/` 路径的时候，会访问 `/usr/share/nginx/html/index.html` 文件。

@router 的作用是，当访问 `/wsm/` 路径的时候，会访问 `/index.html` 文件，然后交给路由在处理请求资源。


### 反向代理

```lua
location /user_server {
    proxy_pass http://10.206.16.15:8010;
    rewrite ^/user_server/(.*)$ /$1 break;
    add_header Access-Control-Allow-Origin *;
    add_header Access-Control-Allow-Methods *;
}
```

上面的配置中，我们添加了一个 location，这个 location 的作用是，当访问 `/user_server` 路径的时候，会访问 `http://10.206.16.15:8010` 地址，
这样就实现了反向代理。
