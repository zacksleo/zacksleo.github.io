# 鸿蒙Flutter插件精选：wechat_camera_picker —— 微信风格相机选择器，选图也能这么优雅

大家好呀～艾玛又来啦！🦊

上一期我们介绍了 **photo_manager** 提供了强大的相册管理能力。有没有一个插件能让你在 Flutter 里拥有微信风格的拍照和选图体验呢？——**wechat_camera_picker** 来了！📱

你有没有羡慕过微信的拍照界面？取景框底部按快门、左右滑动切换前后摄像头、顶部闪关灯和滤镜按钮……UI 设计得既简洁又好看。

现在，你可以用这个插件在你的 App 里实现一模一样的体验！而且它已经在 v4.5.0 版本支持了鸿蒙平台！🎉

---

## 痛点

- **image_picker 的相机界面太简陋**：就是系统相机，样式完全不可控
- **自己写相机 UI 工作量巨大**：自定义相机预览、快门、切换摄像头、闪光灯……还要处理各种设备的适配
- **图片选择器交互体验差**：很多现成的选图组件交互不流畅，卡顿、适配差
- **微信风格是用户最熟悉的**：微信的拍照和选图交互已经培养了用户的习惯，用类似的交互用户上手零成本

---

## 核心特性

- ✅ **微信风格相机界面**：熟悉的取景框、快门、切换摄像头 UI
- ✅ **支持前后摄像头切换**：一键翻转
- ✅ **闪光灯控制**：自动、开启、关闭、常亮
- ✅ **图片多选**：支持同时选择多张图片
- ✅ **相册选择集成**：拍照和相册选择无缝切换
- ✅ **支持视频拍摄**：内置视频录制功能
- ✅ **自定义底部提示**：支持自定义提示文案
- ✅ **主题定制**：适配 Dark Mode，支持自定义主题颜色
- ✅ **鸿蒙全平台**：Android、iOS、Web、OHOS 全面支持

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  wechat_camera_picker: ^4.5.0
```

```bash
flutter pub get
```

### 2. 权限配置

在 `ohos/entry/src/main/module.json5` 中：

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.CAMERA"
      },
      {
        "name": "ohos.permission.READ_MEDIA"
      },
      {
        "name": "ohos.permission.MICROPHONE"
      }
    ]
  }
}
```

### 3. 打开相机

```dart
import 'package:wechat_camera_picker/wechat_camera_picker.dart';

// 打开相机拍照
final asset = await CameraPicker.pickFromCamera(context);

if (asset != null) {
  // 获取照片数据
  final file = await asset.file;
  // 展示或上传图片
  setState(() => _imageFile = file);
}
```

### 4. 打开相册多选

```dart
// 打开相册选择器
final assets = await AssetPicker.pickAssets(
  context,
  pickerConfig: AssetPickerConfig(
    // 最大选择 9 张
    maxAssets: 9,
    // 图片和视频都支持
    requestType: RequestType.common,
    // 主题配置
    themeColor: Colors.teal,
    // 网格列数
    gridCount: 3,
    // 选中的图标
    specialItemIndex: 0, // 拍照入口
    specialItemBuilder: (context) => const CameraIcon(),
  ),
);

if (assets != null && assets.isNotEmpty) {
  // 处理选中的图片
  for (final asset in assets) {
    final file = await asset.file;
    // 上传或展示...
  }
}
```

### 5. 拍照并选图混合模式

```dart
// 拍照 + 选图混合体验（类似微信）
final assets = await AssetPicker.pickAssets(
  context,
  pickerConfig: AssetPickerConfig(
    maxAssets: 9,
    specialItemIndex: 0, // 第一个位置显示拍照入口
    specialItemBuilder: (context) {
      return GestureDetector(
        onTap: () async {
          // 打开相机拍照
          final asset = await CameraPicker.pickFromCamera(context);
          if (asset != null) {
            // 拍照后回到选择器并包含拍的照片
            Navigator.of(context).pop([asset]);
          }
        },
        child: Icon(Icons.camera_alt, color: Colors.white),
      );
    },
  ),
);
```

### 6. 自定义主题

```dart
final assets = await AssetPicker.pickAssets(
  context,
  pickerConfig: AssetPickerConfig(
    themeColor: const Color(0xFF07C160), // 微信绿
    textDelegate: EnglishAssetPickerTextDelegate(),
    // 也可以使用 CFAssetPickerTextDelegate 或自定义
  ),
);
```
