# 鸿蒙Flutter插件精选：aiagent_ohos —— 鸿蒙 AI Agent，智能体赋能 App

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **petalmaps_ohos** 花瓣地图的导航能力。今天要介绍的是这个系列的压轴之作——**AI Agent** 智能体插件！

这是最新、最前沿的插件之一——**aiagent_ohos**。它把鸿蒙 AI 智能体的能力带到了 Flutter 中！

说到 AI Agent，大家可能想到的是小艺、Siri 这样的语音助手。实际上，鸿蒙的 AI Agent 能力远不止语音交互——它能帮你：

- 让 App 拥有自然语言理解和交互能力
- 执行复杂的多步任务（打开 App → 搜索 → 下单）
- 理解用户意图并调起系统/应用能力
- 甚至创建和管理你的自定义智能体 🤖

---

## 痛点

- **AI 能力集成门槛高**：大模型、Agent 框架、工具链……自己搭一套 AI 能力要很多背景知识
- **鸿蒙 AI Agent 原生集成复杂**：要调 Agent SDK、配置技能、处理 ArkTS 桥接
- **Flutter 端缺乏 AI 能力**：纯 Dart 端没有合理的 AI Agent 框架可用
- **用户越来越期待 AI 功能**：现在的 App 如果完全没有 AI 能力，总感觉少了点什么

---

## 核心特性

- ✅ **鸿蒙 AI Agent 能力封装**：将鸿蒙 Agent SDK 的核心能力暴露给 Flutter
- ✅ **意图识别**：自然语言理解，识别用户的操作意图
- ✅ **多轮对话**：支持与 AI Agent 进行多轮对话交互
- ✅ **技能调用**：Agent 可以调用系统预定义技能（打电话、发短信、导航等）
- ✅ **自定义技能**：支持开发者注册自定义技能供 Agent 调用
- ✅ **事件回调**：完整的状态和结果回调
- ✅ **轻量集成**：不需要额外配置大模型，直接利用鸿蒙系统级 AI 能力

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  aiagent_ohos: ^0.0.1
```

```bash
flutter pub get
```

### 2. 权限配置

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      }
    ]
  }
}
```

### 3. 初始化 AI Agent

```dart
import 'package:aiagent_ohos/aiagent_ohos.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 初始化 AI Agent
  await AiAgent.init();
  
  runApp(MyApp());
}
```

### 4. 创建并启动 Agent

```dart
// 创建自定义 Agent
final agent = AiAgent(
  name: '小艾助手',
  description: '一个可以帮助用户完成各种任务的智能助手',
  avatarUrl: 'https://example.com/agent_icon.png',
);

// 启动 Agent 会话
final session = await agent.startSession();

// 发送消息
final response = await session.sendMessage('帮我搜索附近的咖啡馆');
print('AI回复: ${response.text}');
```

### 5. 技能调用

```dart
// 注册自定义技能
agent.registerSkill(
  AiSkill(
    name: '查天气',
    description: '查询指定城市的天气信息',
    handler: (params) async {
      final city = params['city'] ?? '北京';
      // 调用天气 API
      final weather = await getWeather(city);
      return '${city}今天天气: ${weather}';
    },
  ),
);

// Agent 会自动根据用户意图调用匹配的技能
// 用户说 "北京今天天气怎么样" → Agent 自动调起查天气技能
```

### 6. 多轮对话

```dart
// 多轮对话（Agent 会记住上下文）
await session.sendMessage('帮我查一下北京的天气');
// → AI回复: 北京今天晴，15-28°C

await session.sendMessage('那明天呢？');
// → AI回复（基于上下文）: 北京明天多云，18-26°C

await session.sendMessage('适合出去玩吗？');
// → AI回复（推理）: 明天北京多云，温度适宜，适合外出活动！🌤️
```

### 7. Agent 事件监听

```dart
// 监听 Agent 的各种事件
session.addListener((event) {
  switch (event.type) {
    case AiEventType.thinking:
      print('Agent 正在思考...');
      break;
    case AiEventType.skillInvoked:
      print('Agent 调用了技能: ${event.skillName}');
      break;
    case AiEventType.responseReady:
      print('Agent 回复就绪');
      break;
    case AiEventType.error:
      print('发生了错误: ${event.message}');
      break;
  }
});
```

## 环境要求

- Flutter SDK >= 3.0.0
- 鸿蒙系统 API 10+（AI Agent 需要较新系统版本支持）
- 华为开发者联盟账号（已开通 AI Agent 服务）
