# 鸿蒙Flutter插件精选：flutter_webview_plugin_ohos —— Flutter社区经典WebView插件的OHOS移植

大家好呀～艾玛又来了！🦊

今天要聊的这个插件，相信做 Flutter 开发的同学闭着眼睛都能叫出名字——**flutter_webview_plugin**！没错，就是那个 Flutter 社区里元老级的 WebView 插件，早在 Flutter 还是 1.x 版本的时候就陪伴着大家了。现在，这个社区经典已经正式适配了鸿蒙（OHOS），带来了 **flutter_webview_plugin_ohos**！

做过 Flutter 鸿蒙开发的朋友都知道，鸿蒙内置的 WebView 能力（`web_webview`）通过 `ohos_webview` 联邦插件已经能在 Flutter 中使用了。但如果你原来项目里用的是 `flutter_webview_plugin`，想迁移到鸿蒙怎能一个个改 API？最好的方案就是——**同一个 API，鸿蒙直接支持**！

---

## 痛点

Flutter 项目中加载网页内容，常见的「翻车」场景：

- 🤯 项目原来用 `flutter_webview_plugin` 做了大量 WebView 交互，迁移鸿蒙平台时要重写所有 WebView 代码
- 🤯 鸿蒙自带的 Web 组件虽然强大，但 Flutter 层面的桥接还不够成熟，操作起来门槛高
- 🤯 需要全屏加载 H5 页面、做 JS 注入、H5 和 Flutter 通信，没有一个成熟的插件方案
- 🤯 社区主流的 `webview_flutter` 对鸿蒙的支持还在路上，项目工期不等人
- 🤯 需要自定义 WebView 的 rect（比如只占屏幕下半部分），鸿蒙原生写法太复杂

而 **`flutter_webview_plugin_ohos`** 就是这块拼图的完美答案——它把 `flutter_webview_plugin` 的 API 直接移植到了 OHOS 平台，你原来怎么用 `flutter_webview_plugin`，现在就能怎么用 `flutter_webview_plugin_ohos`，几乎零学习成本！🚀

---

## 核心特性

- ✅ **API 完全对齐**：与 `flutter_webview_plugin` 的 Dart API 100% 一致，迁移几乎零成本
- ✅ **全屏 & 自定义区域**：支持 `WebviewScaffold` 全屏模式和自定义 `Rect` 部分屏幕显示
- ✅ **JavaScript 注入**：`evalJavascript()` 在页面加载完成后可注入任意 JS 代码
- ✅ **事件监听**：URL 变化、加载状态、滚动事件、错误回调一应俱全
- ✅ **导航控制**：前进、后退、刷新、停止加载、判断能否前进/后退
- ✅ **Cookie 管理**：获取和清除 Cookie
- ✅ **多参数配置**：缩放、缓存、LocalStorage、UserAgent、地理位置等 20+ 参数随心配置
- ✅ **隐藏 WebView**：支持后台加载，页面加载完再展示
- ✅ **OHOS 原生实现**：基于 HarmonyOS 的 ArkWeb 引擎，性能和体验原生可靠
- ✅ **BSD 开源协议**：来自 openharmony-sig 官方组织，长期有保障

## 快速上手

### 1. 添加依赖

在 `pubspec.yaml` 的 `dependencies` 中添加：

```yaml
dependencies:
  flutter_webview_plugin: ^0.4.0      # Android/iOS 继续用这个
  flutter_webview_plugin_ohos: ^1.0.0 # OHOS 平台
```

> 💡 这两个包 Dart API 完全一致，`flutter_webview_plugin` 支持 Android 和 iOS，`flutter_webview_plugin_ohos` 支持 OHOS，可以同时添加，互不冲突。

### 2. 全屏 WebView

最简单的用法——直接跳转到一个全屏 WebView 页面：

```dart
import 'package:flutter_webview_plugin/flutter_webview_plugin.dart';

new MaterialApp(
  routes: {
    "/": (_) => new WebviewScaffold(
      url: "https://developer.harmonyos.com",
      appBar: new AppBar(
        title: new Text("鸿蒙开发者官网"),
      ),
      withZoom: true,
      withLocalStorage: true,
    ),
  },
);
```

### 3. 加载等待效果

如果你想在页面加载时显示自定义内容，用 `hidden` 和 `initialChild`：

```dart
new WebviewScaffold(
  url: selectedUrl,
  appBar: new AppBar(title: const Text('加载中...')),
  withZoom: true,
  withLocalStorage: true,
  hidden: true,
  initialChild: Container(
    color: Colors.blueAccent,
    child: const Center(
      child: Text('页面加载中，请稍候...'),
    ),
  ),
);
```

### 4. 监听 WebView 事件

`FlutterWebviewPlugin` 提供单例实例，可以在任何地方监听 WebView 的事件：

```dart
final flutterWebviewPlugin = new FlutterWebviewPlugin();

// 监听 URL 变化
flutterWebviewPlugin.onUrlChanged.listen((String url) {
  print('当前 URL: $url');
});

// 监听加载状态
flutterWebviewPlugin.onStateChanged.listen((WebViewState state) {
  switch (state) {
    case WebViewState.startLoad:
      print('开始加载...');
      break;
    case WebViewState.finishLoad:
      print('加载完成 ✅');
      break;
  }
});

// 监听滚动事件
flutterWebviewPlugin.onScrollYChanged.listen((double offsetY) {
  print('垂直滚动偏移: $offsetY');
});

// 监听加载错误
flutterWebviewPlugin.onError.listen((String error) {
  print('加载出错: $error');
});
```

### 5. JavaScript 注入

页面加载完成后，注入自定义 JS 代码：

```dart
flutterWebviewPlugin.onStateChanged.listen((viewState) async {
  if (viewState.type == WebViewState.finishLoad) {
    // 注入 JS —— 比如修改页面背景色
    flutterWebviewPlugin.evalJavascript(
      "document.body.style.backgroundColor = '#f0f0f0';"
    );
  }
});
```

如果需要注入大量 JS 代码，建议放在 assets 文件中：

```dart
Future<String> loadAndInjectJS(String name) async {
  var givenJS = await rootBundle.loadString('assets/$name.js');
  flutterWebviewPlugin.onStateChanged.listen((viewState) async {
    if (viewState.type == WebViewState.finishLoad) {
      flutterWebviewPlugin.evalJavascript(givenJS);
    }
  });
}
```

### 6. 自定义区域 WebView

只占屏幕一部分，比如做一个底部 300px 的 H5 浮层：

```dart
final flutterWebviewPlugin = new FlutterWebviewPlugin();
flutterWebviewPlugin.launch(
  "https://example.com",
  fullScreen: false,
  rect: new Rect.fromLTWH(
    0.0,
    0.0,
    MediaQuery.of(context).size.width,
    300.0,
  ),
);
```

### 7. 隐藏后台加载

页面加载完再展示给用户：

```dart
final flutterWebviewPlugin = new FlutterWebviewPlugin();
flutterWebviewPlugin.launch(url, hidden: true);

// 等加载完成后展示
flutterWebviewPlugin.onStateChanged.listen((state) {
  if (state.type == WebViewState.finishLoad) {
    flutterWebviewPlugin.show();
  }
});
```

### 8. Cookie 操作

```dart
// 获取所有 Cookie
List<Map<String, dynamic>> cookies = await flutterWebviewPlugin.getCookies();

// 清除 Cookie
await flutterWebviewPlugin.cleanCookies();
```

### 9. 导航控制

```dart
// 前进
await flutterWebviewPlugin.goForward();

// 后退
await flutterWebviewPlugin.goBack();

// 刷新
await flutterWebviewPlugin.reload();

// 停止加载
await flutterWebviewPlugin.stopLoading();

// 判断能否后退
bool canGoBack = await flutterWebviewPlugin.canGoBack();

// 判断能否前进
bool canGoForward = await flutterWebviewPlugin.canGoForward();

// 关闭 WebView
flutterWebviewPlugin.close();

// 释放资源（重要！）
flutterWebviewPlugin.dispose();
```

### 10. launch 完整参数

`launch` 方法支持 20+ 配置参数，几乎覆盖所有 WebView 场景：

```dart
flutterWebviewPlugin.launch(
  url,
  headers: {'Authorization': 'Bearer xxx'},
  withJavascript: true,        // 启用 JS
  clearCache: false,           // 不清理缓存
  clearCookies: false,         // 不清理 Cookie
  hidden: false,               // 显示
  rect: rect,                  // 自定义区域
  userAgent: 'Custom UA',      // 自定义 UA
  withZoom: true,              // 支持缩放
  withLocalStorage: true,      // 启用 LocalStorage
  withLocalUrl: true,          // 支持本地文件
  scrollBar: true,             // 显示滚动条
  supportMultipleWindows: false,
  allowFileURLs: false,
  useWideViewPort: true,       // 宽视口
  geolocationEnabled: false,
  debuggingEnabled: false,     // 调试模式
  ignoreSSLErrors: false,      // 不要在生产环境开！
);
```

## OHOS 实现原理

`flutter_webview_plugin_ohos` 的 OHOS 端基于 HarmonyOS 的 **ArkWeb** 引擎实现。插件架构如下：

| 层级 | 说明 |
|------|------|
| **Dart Layer** | `flutter_webview_plugin_ohos.dart` 导出统一 API（`base.dart`、`javascript_channel.dart`、`webview_scaffold.dart`） |
| **MethodChannel** | Flutter 与 OHOS 原生通过 MethodChannel 通信，调用 WebView 的各项操作 |
| **OHOS Plugin** | `FlutterWebviewPluginOhosPlugin`（ArkTS 实现），注册为 OHOS 平台的 pluginClass |
| **ArkWeb** | HarmonyOS 原生 WebView 引擎，负责实际的页面加载和渲染 |

插件通过标准的 Flutter 插件协议注册：

```yaml
# pubspec.yaml 中的插件声明
flutter:
  plugin:
    platforms:
      ohos:
        package: com.flutter_webview_plugin.flutter_webview_plugin_ohos
        pluginClass: FlutterWebviewPluginOhosPlugin
```

## 写在最后

`flutter_webview_plugin_ohos` 的价值不在于「功能多强大」，而在于**它让已有的 `flutter_webview_plugin` 项目能在鸿蒙平台上无痛运行**。原来用 `flutter_webview_plugin` 做的 H5 页面加载、JS 注入、事件监听、导航控制——全部原封不动地在 OHOS 上跑起来。

说实话，这种「API 对齐」的移植思路对于团队跨平台真的很友好 👏 不需要学习新的 WebView API，不需要重写业务逻辑，一行 `flutter_webview_plugin_ohos: ^1.0.0` 就搞定了。开源在 openharmony-sig 下，长期维护有保障，安心上车 🚗
