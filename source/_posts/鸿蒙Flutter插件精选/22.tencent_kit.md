# 鸿蒙Flutter插件精选：tencent_kit —— 腾讯开放平台一键接入

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **native_image_cropper_ohos** 原生图片裁剪的便利。今天要介绍的是一个「全家桶」级别的插件——**腾讯开放平台 Kit**！

你的 App 需要：

- 接入 QQ 登录 / 微信登录？
- 分享内容到 QQ / 微信？
- 使用腾讯地图 WebService API？
- 调用腾讯云 AI 能力？

如果每个功能都要单独接一个 SDK，项目依赖会变得非常臃肿。而 **tencent_kit** 做的就是一件事——把腾讯开放平台的各种能力整合成一个统一的 Flutter 插件，并且已经支持鸿蒙！🚀

---

## 痛点

- **腾讯各 SDK 各自为政**：QQ 登录、微信分享、腾讯地图……每个 SDK 都有自己的接入方式和配置流程
- **Flutter 集成各 SDK 要写很多原生代码**：每个 SDK 都要写原生桥接层，工作量成倍增加
- **鸿蒙支持参差不齐**：有些 SDK 出了鸿蒙版有些没有，开发者需要自己判断和适配
- **权限配置复杂**：微信 SDK、QQ SDK 各有各的签名和权限要求

---

## 核心特性

- ✅ **QQ 登录/分享**：支持 QQ 授权登录、分享图文到 QQ
- ✅ **微信登录/分享**：支持微信授权登录、分享到微信好友/朋友圈
- ✅ **腾讯地图集成**：提供腾讯地图的定位、POI 搜索、路线规划等能力
- ✅ **统一 API 设计**：所有腾讯服务使用一致的 Flutter API
- ✅ **鸿蒙原生支持**：鸿蒙平台上使用华为的兼容能力桥接腾讯 SDK
- ✅ **简洁的配置**：统一管理各 AppID 和密钥配置
- ✅ **完整的回调处理**：登录成功/失败、分享成功/取消 全链路回调

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  tencent_kit: ^6.2.0
```

```bash
flutter pub get
```

### 2. 初始化配置

```dart
import 'package:tencent_kit/tencent_kit.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 初始化腾讯 Kit
  await TencentKit.init(
    qqAppId: '你的QQ AppID',          // 可选
    wxAppId: '你的微信 AppID',        // 可选
    wxUniversalLink: '你的 Universal Link', // iOS 需要
  );
  
  runApp(MyApp());
}
```

### 3. QQ 登录

```dart
// QQ 授权登录
final result = await TencentKit.qqLogin();

if (result.success) {
  print('QQ 登录成功');
  print('openId: ${result.openId}');
  print('accessToken: ${result.accessToken}');
  print('用户信息: ${result.userInfo}');
}
```

### 4. 分享到 QQ

```dart
// 分享文字到 QQ
await TencentKit.qqShareText('分享一段文字');

// 分享图片到 QQ
await TencentKit.qqShareImage(
  imagePath: '/path/to/image.jpg',
  title: '分享图片',
);

// 分享链接到 QQ
await TencentKit.qqShareLink(
  title: '标题',
  description: '描述',
  url: 'https://example.com',
  imageUrl: 'https://example.com/thumb.jpg',
);
```

### 5. 微信登录

```dart
// 微信授权登录
final result = await TencentKit.wxLogin();

if (result.success) {
  print('微信登录成功');
  print('code: ${result.code}');       // 用于换取 access_token
  print('openId: ${result.openId}');
}
```

### 6. 分享到微信

```dart
// 分享到微信好友
await TencentKit.wxShareToSession(
  title: '标题',
  description: '描述',
  url: 'https://example.com',
  imageUrl: 'https://example.com/thumb.jpg',
);

// 分享到朋友圈
await TencentKit.wxShareToTimeline(
  title: '标题',
  url: 'https://example.com',
  imageUrl: 'https://example.com/thumb.jpg',
);
```

### 7. 事件监听

```dart
// 监听回调事件
TencentKit.addListener((event) {
  switch (event.type) {
    case TencentEventType.qqLoginSuccess:
      print('QQ 登录成功');
      break;
    case TencentEventType.qqShareSuccess:
      print('QQ 分享成功');
      break;
    case TencentEventType.wxLoginSuccess:
      print('微信登录成功');
      break;
    case TencentEventType.wxShareSuccess:
      print('微信分享成功');
      break;
    case TencentEventType.error:
      print('发生错误: ${event.message}');
      break;
  }
});
```

## 环境要求

- Flutter SDK >= 3.0.0
- 需要在腾讯开放平台注册应用并获取 AppID
- 鸿蒙系统 API 9+
- 微信分享需要应用签名校验

---

> **特别说明**：在鸿蒙平台上，QQ 和微信的登录/分享功能是通过华为的兼容能力实现的，具体支持程度取决于各腾讯系 App 的鸿蒙适配进度。建议在真机上测试确认后再正式发布。
>
