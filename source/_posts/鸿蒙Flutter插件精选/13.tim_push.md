# 鸿蒙Flutter插件精选：tim_push —— 腾讯推送消息，鸿蒙也能收得到

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **app_installer_ohos** 帮大家解决了鸿蒙上的应用安装问题。今天要来聊一个和「消息触达」相关的插件——**腾讯移动推送**！

消息推送是 App 的「生命线」——促活、拉新、订单通知、活动提醒……全都靠推送。如果你的 App 接入了腾讯移动推送（TPNS / 信鸽），那在鸿蒙平台上怎么实现呢？

别担心，**tim_push** 就是腾讯移动推送的 Flutter 插件，已经支持鸿蒙平台！让你的鸿蒙用户也能实时收到推送消息 📨

---

## 痛点

- **腾讯推送官方插件不支持鸿蒙**：社区标准的 `tpns_flutter_plugin` 只支持 Android 和 iOS
- **华为推送虽然能用，但管理和分析分散**：你已经用腾讯推送统一管理了 iOS 和 Android，鸿蒙又多一个渠道，后台看数据费劲
- **自建推送通道成本高**：长连接、心跳、重连机制……想想就头大
- **推送数据对不上**：三个平台用不同的推送服务，统计到的到达率、点击率各有各的口径，没法对比

---

## 核心特性

- ✅ **统一推送服务**：继续使用腾讯移动推送后台，一站式管理 Android/iOS/OHOS 推送
- ✅ **支持鸿蒙 HMS 推送通道**：自动调用华为推送服务，利用系统级通道保活
- ✅ **消息类型丰富**：通知栏消息、透传消息、富媒体消息全支持
- ✅ **标签与账号绑定**：按标签推送、按账号推送、按设备推送
- ✅ **本地通知兼容**：也支持本地通知的展示
- ✅ **点击事件回调**：通知被点击后的自定义事件处理
- ✅ **精准数据统计**：推送到达、展示、点击全链路数据回传

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  tim_push: ^1.2.1
```

```bash
flutter pub get
```

### 2. 初始化推送

```dart
import 'package:tim_push/tim_push.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 初始化腾讯推送
  await TimPush.init(
    androidAccessId: 123456789,
    androidAccessKey: '您的Android AccessKey',
    iosAccessId: 123456789,
    iosAccessKey: '您的iOS AccessKey',
    ohosAccessId: 123456789,     // 鸿蒙专用
    ohosAccessKey: '您的OHOS AccessKey',
  );
  
  runApp(MyApp());
}
```

> 鸿蒙推送需要在腾讯移动推送控制台开通 **HarmonyOS** 通道并获取 AccessId / AccessKey。

### 3. 注册推送回调

```dart
// 注册回调监听
TimPush.registerMessageHandler(
  onMessageOpened: (message) {
    print('用户点击了通知: ${message.title}');
    // 根据消息内容跳转页面
    navigateToTarget(message.ext);
  },
  onMessageReceived: (message) {
    print('收到推送消息: ${message.content}');
  },
  onNotificationShowed: (notification) {
    print('通知已展示: ${notification.id}');
  },
);
```

### 4. 获取设备 Token

```dart
final token = await TimPush.getToken();
print('设备推送 Token: $token');

// 将 Token 上报到你的服务器
await reportTokenToServer(token);
```

### 5. 标签与账号管理

```dart
// 设置用户标签
await TimPush.setTag(['vip_user', 'android_user']);

// 绑定用户账号
await TimPush.bindAccount('user_12345');

// 解绑用户账号
await TimPush.unbindAccount('user_12345');

// 删除标签
await TimPush.deleteTag('old_tag');
```

## 环境要求

- Flutter SDK >= 3.0.0
- 腾讯移动推送（TPNS）服务已开通，并启用 HarmonyOS 通道
- 鸿蒙系统 API 9+
- 需要在华为开发者联盟开通 **Push Kit**
