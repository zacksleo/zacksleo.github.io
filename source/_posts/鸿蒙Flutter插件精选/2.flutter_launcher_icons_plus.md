# 鸿蒙Flutter插件精选：flutter_launcher_icons_plus —— 一行命令，全平台启动图标全搞定

大家好呀！上一期我们聊了**app_set_id_ohos**，这次带来的是开发中另一个高频需求——**App 启动图标生成**。

每次给 App 换图标都要手动切图、配一堆平台目录？Android 要 mipmap、iOS 要 Assets.xcassets、还得适配自适应图标……现在连**鸿蒙**也来凑热闹了 😂

好消息是——**flutter_launcher_icons_plus** 已经支持 OHOS 了！一行命令，Android、iOS、Web、Windows、macOS 和 **鸿蒙**的图标全部自动生成。

---

## 痛点

Flutter 项目要换启动图标，手动操作有多痛苦？

- 各平台图标尺寸、命名规则五花八门
- Android 自适应图标要配 foreground + background
- iOS 18+ 还要支持深色图标和着色图标
- 鸿蒙的图标又要放到 `ohos/AppScope/resources/base/media/` 下面
- 多 flavor 项目更是噩梦

而社区经典的 [`flutter_launcher_icons`](https://pub.dev/packages/flutter_launcher_icons) 已经停更，不支持鸿蒙。

现在，**`flutter_launcher_icons_plus`** 就是你的救星 🚀

---

## 核心特性

- ✅ **一行命令**生成全平台启动图标
- ✅ **原生支持 OHOS**，自动写入 `ohos/AppScope/resources/base/media/`
- ✅ **Android 自适应图标**（foreground / background / monochrome）
- ✅ **iOS 18+ 深色图标 & 着色图标**支持
- ✅ **Web / Windows / macOS** 全覆盖
- ✅ **分层图标模式**：OHOS 也支持 layered-image
- ✅ **Flavor 多环境**支持
- ✅ 自动更新 `module.json5` / `app.json5`，无需手动改配置

---

## 快速上手

### 1. 添加依赖

```yaml
dev_dependencies:
  flutter_launcher_icons_plus: ^0.15.0
```

### 2. 创建配置文件

方案一：自动生成

```bash
dart run flutter_launcher_icons_plus:generate
```

方案二：在 `pubspec.yaml` 中直接配置

```yaml
flutter_launcher_icons_plus:
  image_path: "assets/icon/icon.png"
  android: true
  ios: true
  ohos: true
  web:
    generate: true
    image_path: "assets/icon/icon.png"
    background_color: "#ffffff"
    theme_color: "#ffffff"
  windows:
    generate: true
    image_path: "assets/icon/icon.png"
    icon_size: 48
  macos:
    generate: true
    image_path: "assets/icon/icon.png"
```

对于鸿蒙**分层图标**（推荐），配置更精细：

```yaml
flutter_launcher_icons_plus:
  image_path: "assets/icon/icon.png"
  ohos:
    generate: true
    image_path: "assets/icon/icon.png"           # 用作 startIcon
    image_path_foreground: "assets/icon/foreground.png"
    image_path_background: "assets/icon/background.png"
  android:
    adaptive_icon_foreground: "assets/icon/foreground.png"
    adaptive_icon_background: "#FFFFFF"
  ios: true
```

### 3. 执行生成

```bash
flutter pub get
dart run flutter_launcher_icons_plus
```

大功告成！去检查各平台的 icon 目录，全部自动替换好了 ✨

## OHOS 生成效果

执行后，插件会自动处理以下内容：

| 文件路径 | 说明 |
|---------|------|
| `ohos/AppScope/resources/base/media/icon.png` | 单图模式启动图标 |
| `ohos/entry/src/main/resources/base/media/icon.png` | 单图模式入口图标 |
| `ohos/AppScope/resources/base/media/foreground.png` | 分层模式前景 |
| `ohos/AppScope/resources/base/media/background.png` | 分层模式背景 |
| `ohos/entry/src/main/resources/base/media/foreground.png` | 分层模式前景 |
| `ohos/entry/src/main/resources/base/media/background.png` | 分层模式背景 |
| `ohos/entry/src/main/resources/base/media/startIcon.png` | 启动窗口图标 |
| `ohos/entry/src/main/resources/base/media/layered_image.json` | 分层图片配置文件（自动生成） |

插件还会自动更新 `module.json5` 中的 `icon` 和 `startWindowIcon` 引用，完全不需要你手动改任何配置文件 👍
