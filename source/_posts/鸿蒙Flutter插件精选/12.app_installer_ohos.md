# 鸿蒙Flutter插件精选：app_installer_ohos —— 静默安装、版本更新，鸿蒙也能行

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **change_app_name** 一键改应用名的便利。今天要介绍的插件解决了 App 开发中的一个关键需求——**安装与更新**！

你的 App 需要下载并安装其他应用？或者需要检测某个应用是否已安装？再或者要做 App 内更新功能？

在 Android 上可以用 `package_manager`，在 iOS 上没法直接安装第三方应用……那鸿蒙呢？🤔

**app_installer_ohos** 就是专门为鸿蒙打造的 App 安装管理工具，帮你搞定鸿蒙设备上的应用安装、卸载、更新等操作！

---

## 痛点

- **鸿蒙安装 API 不好找**：ArkTS 里安装 APK/HAP 需要 `@ohos.bundle.installer`、`@ohos.bundle.bundleManager` 等一堆底层 API
- **权限管理复杂**：安装应用需要 `ohos.permission.INSTALL_BUNDLE` 等系统权限，配置门槛高
- **安装进度难追踪**：原生安装接口回调复杂，要自己处理进度监听
- **版本检测要自己写**：需要判断当前版本和目标版本，手动写版本比较逻辑
- **卸载应用流程繁琐**：卸载也要调 bundleManager，异常处理都得自己写

---

## 核心特性

- ✅ **安装 HAP/APK**：支持安装鸿蒙 HAP 包和兼容的 APK 文件
- ✅ **卸载应用**：通过包名一键卸载已安装的应用
- ✅ **版本检测**：获取已安装应用的版本号和版本名称
- ✅ **安装进度回调**：实时监听安装进度，UI 展示更友好
- ✅ **是否已安装检测**：判断指定包名应用是否已安装
- ✅ **静默安装支持**：企业应用或系统级场景支持静默安装
- ✅ **安装结果回调**：成功/失败/取消等完整回调

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  app_installer_ohos: ^1.0.0
```

```bash
flutter pub get
```

### 2. 权限配置

在 `ohos/entry/src/main/module.json5` 中添加权限：

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.INSTALL_BUNDLE"
      },
      {
        "name": "ohos.permission.GET_BUNDLE_INFO"
      }
    ]
  }
}
```

### 3. 安装应用

```dart
import 'package:app_installer_ohos/app_installer_ohos.dart';

// 安装本地 HAP 文件
final result = await AppInstaller.install(
  hapPath: '/data/app/example.hap',
  onProgress: (progress) {
    print('安装进度: $progress%');
  },
);

if (result.success) {
  print('安装成功！');
} else {
  print('安装失败: ${result.errorMessage}');
}
```

### 4. 卸载应用

```dart
final result = await AppInstaller.uninstall(
  bundleName: 'com.example.app',
);
```

### 5. 检查应用状态

```dart
// 检测是否已安装
final isInstalled = await AppInstaller.isAppInstalled(
  bundleName: 'com.example.app',
);

// 获取应用版本信息
final version = await AppInstaller.getAppVersion(
  bundleName: 'com.example.app',
);

if (version != null) {
  print('版本号: ${version.versionCode}');
  print('版本名称: ${version.versionName}');
}
```

### 6. 检查更新

```dart
final currentVersion = await AppInstaller.getAppVersion(
  bundleName: 'com.example.app',
);

// 比较版本，决定是否需要更新
if (currentVersion != null && currentVersion.versionCode < 20) {
  // 有新版本，下载并安装
  await AppInstaller.install(hapPath: '/data/app/v2.hap');
}
```

## 环境要求

- Flutter SDK >= 3.0.0
- 鸿蒙系统 API 9+
- 需要 `ohos.permission.INSTALL_BUNDLE` 权限（部分场景需要系统级权限）

---

> **注意**：普通应用安装其他应用需要用户授权，静默安装通常需要企业签名或系统级应用权限。如果你是做应用商店或企业内部分发，这个插件就是神器！
