# 鸿蒙Flutter插件精选：share_bridge_wechat_ohos —— 微信分享鸿蒙化，一行代码搞定

![cover](/images/2026/06/share_bridge_wechat_ohos_cover.png)

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **aiagent_ohos** 鸿蒙 AI Agent 的前沿能力。今天回到一个更务实的场景——**微信分享**。

微信分享几乎是每个 App 的标配功能。分享文章到好友、分享截图到朋友圈，这些操作在 Android 和 iOS 上已经有成熟方案，但在 HarmonyOS NEXT 上，事情就没那么简单了：

- 微信官方出了 OpenSDK for OHOS，但怎么接入 Flutter？
- 分享到好友和朋友圈各走什么接口？
- 回调怎么处理？要不要像 QQ 那样搞签名回调？

今天要介绍的 **share_bridge_wechat_ohos**，就是把这一切封装好的答案。

---

## 痛点

- **微信分享接入门槛不低**：OpenSDK 文档、module.json5 配置、签名校验……每一步都不能错
- **Flutter 端缺乏统一封装**：微信分享要写原生桥接代码，Android、iOS、HarmonyOS 各来一套
- **鸿蒙 OpenSDK 刚出不久**：社区资料少，踩坑了要自己填
- **回调处理容易被忽略**：分享成功后拿不到回调，用户取消了也不知道，体验很差

---

## 核心特性

- ✅ **四类分享全覆盖**：好友网页、朋友圈网页、好友图片、朋友圈图片
- ✅ **Federated Plugin 架构**：依赖 `share_bridge_wechat` 自动带出 OHOS 实现，无需手动选择平台包
- ✅ **统一 API**：三端（Android / iOS / HarmonyOS）用同一套 `ShareManager` API，业务代码零改动
- ✅ **不需要签名回调**：微信 HarmonyOS 与 QQ 不同，不需要 `qqHarmonySigner` 这种后台签名流程
- ✅ **完整的回调通知**：分享成功 / 取消 / 错误，通过 `ShareBridgeWechatPlugin.handleWant` 统一接收
- ✅ **轻量级**：只做分享，不包含登录、支付、OAuth 等重逻辑
- ✅ **支持图片分享**：本地文件和内存字节均可，网络图片需要业务侧先下载

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  share_bridge_wechat: ^0.1.0-dev.4
```

```bash
flutter pub get
```

> 注意：不需要直接依赖 `share_bridge_wechat_ohos`。它是通过 Flutter 的 `default_package` 机制自动导入的。依赖 `share_bridge_wechat` 就够了，HarmonyOS 平台会自动拉取 `share_bridge_wechat_ohos`。

### 2. 初始化微信 Provider

```dart
import 'package:share_bridge_core/share_bridge_core.dart';
import 'package:share_bridge_wechat/share_bridge_wechat.dart';

final manager = ShareManager();

await manager.register(
  WechatShareProvider(
    appId: '你的微信 AppID',
    universalLink: 'https://example.com/wechat/', // iOS 需要
  ),
);
```

### 3. 检查微信是否已安装

```dart
final installed = await manager.isInstalled(ShareClient.wechat);
if (!installed) {
  // 提示用户安装微信
}
```

### 4. 分享网页到微信好友

```dart
final result = await manager.share(
  channel: ShareChannel.wechatSession,
  content: const ShareContent.webpage(
    title: '鸿蒙Flutter插件精选',
    description: '分享到微信好友的精彩内容',
    url: 'https://blog.shaohushuo.com',
  ),
);

if (result.code == ShareResultCode.success) {
  print('分享成功！');
} else if (result.code == ShareResultCode.cancel) {
  print('用户取消了分享');
} else {
  print('分享失败: ${result.code}');
}
```

### 5. 分享网页到朋友圈

```dart
final result = await manager.share(
  channel: ShareChannel.wechatTimeline,
  content: const ShareContent.webpage(
    title: '鸿蒙Flutter插件精选',
    description: '分享到朋友圈的精彩内容',
    url: 'https://blog.shaohushuo.com',
  ),
);
```

### 6. 分享图片

```dart
// 从本地文件分享图片
final result = await manager.share(
  channel: ShareChannel.wechatSession,
  content: ShareContent.image(
    imagePath: '/path/to/image.jpg',
  ),
);

// 从内存字节分享图片
final result = await manager.share(
  channel: ShareChannel.wechatTimeline,
  content: ShareContent.image(
    imageBytes: imageBytes, // Uint8List
  ),
);
```

## 鸿蒙宿主配置

微信分享在鸿蒙上需要一些原生配置，这部分是绕不开的。但好消息是——**只有微信才需要用 OpenSDK 配置一次，业务代码完全不用变**。

### module.json5 添加查询 scheme

```json5
{
  "module": {
    "abilities": [
      {
        "name": "EntryAbility",
        // ...
        "skills": [
          {
            "actions": ["system.want.action"]
          }
        ]
      }
    ],
    "querySchemes": ["weixin", "wxopensdk"]
  }
}
```

### EntryAbility 转发回调

```ts
// EntryAbility.ets
import Want from '@ohos.app.ability.Want';
import AbilityConstant from '@ohos.app.ability.AbilityConstant';
import ShareBridgeWechatPlugin from 'share_bridge_wechat_ohos';

// 冷启动
onCreate(want: Want, launchParam: AbilityConstant.LaunchParam) {
  super.onCreate(want, launchParam)
  ShareBridgeWechatPlugin.handleWant(want)
}

// 热启动
onNewWant(want: Want, launchParams: AbilityConstant.LaunchParam): void {
  super.onNewWant(want, launchParams)
  ShareBridgeWechatPlugin.handleWant(want)
}
```

不配这一步的话，分享能发出去，但拿不到微信返回的成功 / 取消 / 错误结果。

### DevEco Studio 配置调试签名

微信 OpenSDK 要求在开放平台注册应用签名，需要在 DevEco Studio 中配置本机调试签名。

## share_bridge 架构简析

如果你好奇这套代码为什么能「一行代码三端运行」，简单说两句：

`share_bridge` 项目采用了 **Federated Plugin** 架构：

```
share_bridge_core          ← 纯 Dart，定义 ShareManager、ShareContent、ShareResultCode
share_bridge_platform_interface  ← 定义平台接口抽象
share_bridge_wechat        ← 主包，聚合各平台实现
  ├── share_bridge_wechat_android  ← Android 实现
  ├── share_bridge_wechat_ios      ← iOS 实现
  └── share_bridge_wechat_ohos     ← HarmonyOS 实现（今天的主题）
```

Flutter 在构建时会根据目标平台自动选择对应的实现包：

```yaml
# share_bridge_wechat 的 pubspec.yaml
flutter:
  plugin:
    platforms:
      android:
        default_package: share_bridge_wechat_android
      ios:
        default_package: share_bridge_wechat_ios
      ohos:
        default_package: share_bridge_wechat_ohos
```

所以业务代码写的 `WechatShareProvider`考和 `manager.share()`，在 HarmonyOS 设备上实际走的是 `share_bridge_wechat_ohos` + 微信 OpenSDK for OHOS。

## 与 tencent_kit 的对比

之前系列里介绍过 **tencent_kit**，它也支持微信分享。两者的区别：

| 对比项 | share_bridge_wechat | tencent_kit |
|--------|-------------------|-------------|
| 定位 | 专注微信分享 | 腾讯全家桶（QQ登录、微信登录、分享、地图） |
| 架构 | Federated Plugin | 单体插件 |
| 鸿蒙实现 | 独立 ohos 包，通过微信 OpenSDK | 通过华为兼容层桥接 |
| 包体积 | 极轻（只含分享） | 较大（含多 SDK） |
| 灵活性 | 可搭配 share_bridge_qq 等组合 | 一步到位 |

如果你的 App 只需要微信分享，**share_bridge_wechat** 是更轻量的选择；如果还需要 QQ 登录、微信登录等能力，**tencent_kit** 更方便。
