# 鸿蒙Flutter插件精选：native_image_cropper_ohos —— 原生图片裁剪，精准而优雅

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **wechat_camera_picker** 实现微信风格相机和选图体验。今天要介绍的插件是图片编辑流程中承上启下的重要一环——**图片裁剪**！

选好图片之后做什么？很多时候就是——裁剪！

头像裁成 1:1 方形、身份证裁出正反面、商品图裁出主体……几乎所有带图片上传功能的应用都离不开图片裁剪。

`native_image_cropper_ohos` 就是那个让你在鸿蒙上也能享受原生级图片裁剪体验的插件！✂️

---

## 痛点

- **Flutter 裁剪库性能不给力**：纯 Dart 实现的裁剪器在处理大图时掉帧严重
- **原生裁剪功能强大但集成麻烦**：鸿蒙的 Image Cropper 功能很全，但要自己写 ArkTS 桥接
- **裁剪交互体验参差不齐**：手势缩放、旋转、拖拽框……自己做一遍交互优化至少一周
- **各平台裁剪器不统一**：Android 用 uCrop、iOS 用 TOCropViewController、鸿蒙再换一个，代码维护量巨大

---

## 核心特性

- ✅ **原生性能**：基于鸿蒙原生 Image Cropper 实现，GPU 加速，裁剪大图丝滑流畅
- ✅ **丰富的裁剪形状**：支持圆形、正方形、3:2、4:3、16:9 等预设比例
- ✅ **自由裁剪**：也支持完全自由的手动裁剪框
- ✅ **手势交互**：双指缩放、平移、旋转，交互体验流畅
- ✅ **图片旋转**：支持 -90° / 90° 旋转图片
- ✅ **图片翻转**：支持水平/垂直翻转
- ✅ **高质量输出**：支持自定义输出图片质量（JPEG/PNG）
- ✅ **统一 API**：与社区 `image_cropper` API 保持一致，降低迁移成本

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  native_image_cropper_ohos: ^0.1.0
```

```bash
flutter pub get
```

### 2. 基本裁剪

```dart
import 'package:native_image_cropper_ohos/native_image_cropper_ohos.dart';

final cropper = NativeImageCropperOhos();

// 打开裁剪界面
final croppedFile = await cropper.cropImage(
  sourcePath: '/path/to/original.jpg',        // 原图路径
  targetPath: '/path/to/cropped.jpg',          // 裁剪后输出路径
  aspectRatio: CropAspectRatio(ratioX: 1, ratioY: 1),  // 1:1 方形
  quality: 95,                                         // 输出质量
);

if (croppedFile != null) {
  print('裁剪完成: ${croppedFile.path}');
} else {
  print('用户取消了裁剪');
}
```

### 3. 预设裁剪比例

```dart
// 身份证（宽高比约 1.586:1）
final idCard = await cropper.cropImage(
  sourcePath: '/path/to/id_card.jpg',
  targetPath: '/path/to/id_card_cropped.jpg',
  aspectRatio: CropAspectRatio(ratioX: 85.6, ratioY: 54),
);

// 头像（圆形裁剪）
final avatar = await cropper.cropImage(
  sourcePath: '/path/to/photo.jpg',
  targetPath: '/path/to/avatar.jpg',
  cropStyle: CropStyle.circle,     // 圆形裁剪
  aspectRatio: CropAspectRatio(ratioX: 1, ratioY: 1),
);

// 自由裁剪（无固定比例）
final freeCrop = await cropper.cropImage(
  sourcePath: '/path/to/photo.jpg',
  targetPath: '/path/to/free_crop.jpg',
  cropStyle: CropStyle.rectangle,  // 矩形自由裁剪框
  freeStyleCropEnabled: true,      // 允许自由调整比例
);
```

### 4. 结合图片选择器使用

```dart
// 选图 → 裁剪 → 上传
Future<void> pickAndCropAndUpload() async {
  // 1. 选图
  final assets = await AssetPicker.pickAssets(
    context,
    pickerConfig: AssetPickerConfig(maxAssets: 1),
  );
  
  if (assets == null || assets.isEmpty) return;
  
  final file = await assets.first.file;
  
  // 2. 裁剪（1:1 头像）
  final cropped = await cropper.cropImage(
    sourcePath: file!.path,
    targetPath: '${file.parent.path}/avatar_cropped.jpg',
    aspectRatio: CropAspectRatio(ratioX: 1, ratioY: 1),
    quality: 90,
  );
  
  if (cropped == null) return;
  
  // 3. 上传
  // await uploadFile(cropped);
}
```

| 场景 | 比例 | 用途 |

| 正方形 | 1:1 | 头像、个人主页 |

| 4:3 | 4:3 | 普通照片 |
| 16:9 | 16:9 | 横幅、封面图 |
| 3:2 | 3:2 | 打印照片 |
| 圆形 | — | 圆形头像、徽章 |
| 自由 | 无限制 | 一般裁剪需求 |
