# 鸿蒙Flutter插件精选：image_compress_plus_ohos —— 批量压缩，告别大图

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **flutter_volume_controller** 的音量控制。今天要介绍的插件解决的是另一个高频痛点——**图片压缩**！

你的 App 需要上传图片？需要压缩相册照片？需要调整图片质量？

图片压缩几乎是所有带图片上传功能的 App 的刚需——头像上传、朋友圈发图、身份认证拍照……但是 Flutter 社区最流行的 `flutter_image_compress` 在鸿蒙上并不直接支持。

好消息是——**image_compress_plus_ohos** 就是 `flutter_image_compress` 的鸿蒙适配方案！让你在鸿蒙上也能愉快地进行图片压缩！🎯

---

## 痛点

- **flutter_image_compress 不支持鸿蒙**：社区最流行的图片压缩插件在 OHOS 上直接不能用
- **原生压缩轮子不好造**：鸿蒙上图片压缩需要 `@ohos.multimedia.image` + `@ohos.file.fs` + 编解码，代码量不小
- **质量和大小控制难平衡**：压缩率、格式、宽高这些参数调整不好，图片要么太大要么糊了
- **批量压缩性能堪忧**：一次性压几十张图，没有好的并发控制，App 直接卡死

---

## 核心特性

- ✅ **支持多种压缩方式**：质量压缩、尺寸压缩、格式转换
- ✅ **保持与 flutter_image_compress 兼容的 API**：减少迁移成本
- ✅ **支持 JPEG、PNG、WebP 格式转换**：想省空间？转 WebP！
- ✅ **保持 EXIF 信息**：可选保留照片的方向、GPS 等元数据
- ✅ **异步非阻塞压缩**：不阻塞 UI 线程
- ✅ **支持 Uint8List 和文件路径**：两种输入方式按需选择

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  image_compress_plus_ohos: ^0.1.0
```

```bash
flutter pub get
```

### 2. 基础使用

```dart
import 'package:image_compress_plus_ohos/image_compress_plus_ohos.dart';

final imageCompress = ImageCompressPlusOhos();

// 从文件压缩
final result = await imageCompress.compress(
  sourcePath: '/path/to/original.jpg',       // 原图路径
  targetPath: '/path/to/compressed.jpg',      // 输出路径
  quality: 80,                                // 质量 1-100
);

print('压缩前大小: ${result.originalSize}');
print('压缩后大小: ${result.compressedSize}');
print('压缩率: ${result.compressionRatio}%');
```

### 3. 按目标大小压缩

```dart
// 压缩到不超过 500KB
final result = await imageCompress.compressWithTargetSize(
  sourcePath: '/path/to/original.jpg',
  targetSizeKB: 500,
);
```

### 4. 调整尺寸并压缩

```dart
// 缩放到最大宽度 1080px，同时压缩质量
final result = await imageCompress.compress(
  sourcePath: '/path/to/original.jpg',
  targetPath: '/path/to/output.jpg',
  quality: 85,
  maxWidth: 1080,
  maxHeight: 1920,
);
```

### 5. 格式转换

```dart
// 将 PNG 转为 JPEG（可以大大减小体积）
final result = await imageCompress.compress(
  sourcePath: '/path/to/image.png',
  targetPath: '/path/to/image.jpg',
  format: CompressFormat.jpeg,
  quality: 90,
);

// 转为 WebP（体积最小）
final result = await imageCompress.compress(
  sourcePath: '/path/to/image.png',
  targetPath: '/path/to/image.webp',
  format: CompressFormat.webp,
  quality: 80,
);
```

### 6. 从内存数据压缩

```dart
// 从 Uint8List 压缩
final Uint8List imageBytes = await loadImageBytes();
final result = await imageCompress.compressFromBytes(
  sourceBytes: imageBytes,
  quality: 70,
  maxWidth: 720,
);
```

## 环境要求

- Flutter SDK >= 3.0.0
- 鸿蒙系统 API 9+
- 读取/写入文件需要 `ohos.permission.READ_MEDIA` / `ohos.permission.WRITE_MEDIA`
