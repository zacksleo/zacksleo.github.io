# 鸿蒙Flutter插件精选：flutter_umeng_common —— 友盟统计鸿蒙化，数据不再有盲区

大家好呀～艾玛又来啦！🦊

上一期介绍了 **url_launcher_harmonyos** 解决了最基础的 URL 启动需求。今天来聊一个对运营和产品同学来说非常重要的话题——**数据统计**！

App 上线了总得看数据——用户量、留存、活跃、事件分析……这些都得靠统计 SDK。但是鸿蒙平台上，很多友盟开发者发现一个问题：友盟官方没有提供鸿蒙 Flutter 插件。

那怎么办？手动埋点？自己搭统计平台？还是干脆放弃鸿蒙的数据追踪？😅

别急！**flutter_umeng_common** 就是来填这个坑的——它把友盟 U-App 统计的鸿蒙 SDK 封装成了 Flutter 插件，让你在鸿蒙上也能愉快地用友盟！

---

## 痛点

- **友盟官方只支持原生 Android/iOS**：鸿蒙平台？暂时还没有官方 Flutter 支持
- **手动集成太复杂**：要从头对接友盟的 ArkTS SDK，配置参数、处理缓存、排查数据……得花不少功夫
- **数据断层**：不上统计，鸿蒙用户的行为全成了盲区，运营做决策没依据
- **多平台数据不统一**：Android 和 iOS 有友盟，鸿蒙没有，三个平台的数据对不上

---

## 核心特性

- ✅ **Flutter 统一 API**：与友盟 Flutter 插件 API 保持一致，Android/iOS/OHOS 三端统一
- ✅ **自动采集基本数据**：设备信息、启动次数、使用时长等基础数据自动采集，无需额外埋点
- ✅ **自定义事件统计**：支持自定义事件上报，灵活追踪业务数据
- ✅ **页面访问统计**：自动记录页面访问路径和停留时长
- ✅ **账户统计**：支持用户账户级统计分析
- ✅ **错误分析**：崩溃和异常信息自动上报
- ✅ **隐私合规**：支持 GDPR 等隐私合规开关

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  flutter_umeng_common: ^0.0.4
```

```bash
flutter pub get
```

### 2. 初始化友盟统计

```dart
import 'package:flutter_umeng_common/flutter_umeng_common.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 初始化友盟统计
  await UmengCommon.init(
    androidAppKey: '您的Android AppKey',
    iosAppKey: '您的iOS AppKey',
    ohosAppKey: '您的鸿蒙 AppKey',  // 鸿蒙专用
    channel: 'huawei',
  );
  
  runApp(MyApp());
}
```

> 鸿蒙 AppKey 需要在友盟后台开通 **HarmonyOS SDK** 服务。

### 3. 页面统计

```dart
class MyHomePage extends StatefulWidget {
  @override
  _MyHomePageState createState() => _MyHomePageState();
}

class _MyHomePageState extends State<MyHomePage> {
  @override
  void initState() {
    super.initState();
    // 进入页面时上报
    UmengCommon.onPageStart('HomePage');
  }

  @override
  void dispose() {
    // 离开页面时上报
    UmengCommon.onPageEnd('HomePage');
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('首页')),
      body: Center(
        child: ElevatedButton(
          onPressed: () {
            // 自定义事件统计
            UmengCommon.onEvent('button_click', {'button_name': 'start'});
          },
          child: Text('开始使用'),
        ),
      ),
    );
  }
}
```

### 4. 统计用户信息

```dart
// 用户登录后上报
await UmengCommon.profileSignInWithPUID('user_12345');

// 用户登出后清除
await UmengCommon.profileSignOff();
```

## 环境要求

- Flutter SDK >= 3.0.0
- 友盟 U-App 统计账号（已开通 HarmonyOS SDK）
- 鸿蒙系统 API 9+
