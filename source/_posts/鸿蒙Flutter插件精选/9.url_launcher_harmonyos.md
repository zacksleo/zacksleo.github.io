# 鸿蒙Flutter插件精选：url_launcher_harmonyos —— 鸿蒙平台 URL 启动，一个都不能少

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **flutter_ohos_ads** 帮大家搞定鸿蒙广告变现。今天要介绍的这个插件虽然小巧，但几乎所有 App 都会用到——**URL 启动器**！

打开一个网页、拨打电话、发送短信、跳转地图……这些都是移动 App 里最基础的能力。Flutter 社区经典的 `url_launcher` 插件已经支持了各大平台，唯独缺少鸿蒙支持。

`url_launcher_harmonyos` 就是来解决这个问题的——它是 `url_launcher` 的鸿蒙平台实现，通过联邦插件机制自动集成，代码都不用改！😎

---

## 痛点

- **url_launcher 不支持鸿蒙**：社区标准插件在鸿蒙上直接报错，只能 fallback 或者自己写原生代码
- **手动实现巨麻烦**：ArkTS 里打开 URL 需要 `@ohos.want`、`@ohos.openLink`、`@ohos.uri` 一堆 API
- **各种 Scheme 都得处理**：`tel:`、`mailto:`、`sms:`、`https:`……每个 Scheme 在鸿蒙上的处理方式都不一样
- **回调结果很头疼**：打开失败还是成功？用户取消？都需要自己处理

---

## 核心特性

- ✅ **完全兼容 url_launcher API**：无需改动现有代码，加依赖即用
- ✅ **支持多种 Scheme**：`https`、`tel`、`mailto`、`sms`、`geo` 等常见 URL Scheme
- ✅ **联邦插件自动加载**：作为 `url_launcher` 的 endorsed 插件，鸿蒙平台自动生效
- ✅ **canLaunch 检测**：支持检查当前设备是否能处理指定 URL
- ✅ **完整的错误处理**：优雅处理不能打开的 URL
- ✅ **轻量无侵入**：不引入额外依赖，对包体积几乎无影响

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  url_launcher: ^6.3.0      # 主包
  url_launcher_harmonyos: ^0.0.1  # 鸿蒙平台实现
```

```bash
flutter pub get
```

### 2. 打开 URL

```dart
import 'package:url_launcher/url_launcher.dart';

// 打开网页
final uri = Uri.parse('https://www.example.com');
if (await canLaunchUrl(uri)) {
  await launchUrl(uri);
} else {
  throw Exception('无法打开链接');
}

// 拨打电话
await launchUrl(Uri.parse('tel:+8613800138000'));

// 发送邮件
final emailUri = Uri(
  scheme: 'mailto',
  path: 'hello@example.com',
  queryParameters: {
    'subject': 'Hello from Flutter',
    'body': '这是一封测试邮件',
  },
);
await launchUrl(emailUri);

// 打开地图（使用华为地图）
await launchUrl(Uri.parse('geo:39.9042,116.4074'));
```

### 3. 配置权限

在 `ohos/entry/src/main/module.json5` 中添加必要的权限：

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      }
    ]
  }
}
```

> 拨打电话可能需要额外配置 `ohos.permission.PLACE_CALL` 权限。

- Flutter SDK >= 3.0.0
