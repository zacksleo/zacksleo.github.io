# 鸿蒙Flutter插件精选：photo_manager —— 相册管理全能选手

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **flutter_charset_detector_ohos** 解决了编码识别的问题。今天要介绍的插件是图片视频相关开发中绕不开的一个——**相册管理器**！

你的 App 需要：

- 读取用户相册里的图片和视频？
- 按相册/文件夹分组展示？
- 支持多选、预览、编辑？
- 保存图片到相册？

在 Flutter 生态里，`photo_manager` 可以说是相册管理的「标准答案」，它提供了丰富而强大的相册访问能力，而且现在已经支持了鸿蒙！📸

---

## 痛点

- **Flutter 官方 image_picker 太基础**：只能单选/相机拍照，没有相册分组、没有多选过滤
- **各平台相册 API 差异大**：Android 的 MediaStore、iOS 的 PHAsset、鸿蒙的 `@ohos.multimedia.mediaLibrary`，各搞一套
- **复杂场景自己实现太慢**：按相册展示、选图过滤、缓存管理、权限处理……从头写至少一星期
- **权限问题防不胜防**：Android 13+ 细粒度权限、iOS 隐私权限、鸿蒙相册权限，一个处理不好就崩溃

---

## 核心特性

- ✅ **读取相册资源**：获取设备上所有图片和视频资源
- ✅ **相册分组**：按相册/文件夹进行资源分组展示
- ✅ **资源过滤**：只显示图片、只显示视频、按时间段筛选
- ✅ **EXIF 信息获取**：获取照片的拍摄时间、地点、设备、尺寸等元数据
- ✅ **缩略图加载**：高效加载指定尺寸的缩略图
- ✅ **保存图片到相册**：支持保存网络图片、本地文件到相册
- ✅ **资源删除**：支持删除相册资源
- ✅ **权限管理**：自动检测和处理相册访问权限
- ✅ **高性能加载**：分页加载、缓存机制，千张照片也不卡

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  photo_manager: ^3.9.0
```

```bash
flutter pub get
```

### 2. 权限配置

在 `ohos/entry/src/main/module.json5` 中：

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.READ_MEDIA"
      },
      {
        "name": "ohos.permission.WRITE_MEDIA"
      }
    ]
  }
}
```

### 3. 请求权限并加载相册

```dart
import 'package:photo_manager/photo_manager.dart';

// Step 1: 请求相册权限
final permission = await PhotoManager.requestPermissionExtend();
if (!permission.isAuth) {
  print('用户拒绝了相册权限');
  return;
}

// Step 2: 获取相册列表
final albums = await PhotoManager.getAssetPathList(
  type: RequestType.common, // common=图片+视频, image=仅图片, video=仅视频
);

for (final album in albums) {
  print('相册: ${album.name} (${album.assetCount}张)');
}
```

### 4. 加载相册里的图片

```dart
// 获取第一个相册的图片（分页加载）
final album = albums.first;

final assets = await album.getAssetListPaged(
  page: 0,     // 第 1 页
  size: 60,    // 每页 60 张
);

// 加载缩略图
for (final asset in assets) {
  final thumbData = await asset.thumbDataWithSize(
    width: 200,
    height: 200,
    quality: 80,
    format: ThumbFormat.jpeg,
  );
  
  // 将 thumbData (Uint8List) 转为 Image 显示
  // Image.memory(thumbData)
}
```

### 5. 保存图片到相册

```dart
// 保存网络图片
final url = 'https://example.com/photo.jpg';
final bytes = await NetworkAssetBundle(Uri.parse(url)).load(url);
final saved = await PhotoManager.editor.saveImage(
  bytes.buffer.asUint8List(),
  title: 'MyPhoto.jpg',
);

// 保存到指定相册
await PhotoManager.editor.saveImageToAlbum(
  bytes.buffer.asUint8List(),
  album,
);

// 保存视频
await PhotoManager.editor.saveVideo(
  File('/path/to/video.mp4'),
  title: 'MyVideo.mp4',
);
```

### 6. 获取图片 EXIF 信息

```dart
final asset = assets.first;
final title = asset.title;            // 文件名
final createDate = asset.createDate;  // 拍摄时间
final lat = asset.latLng?.latitude;   // GPS 纬度
final lng = asset.latLng?.longitude;  // GPS 经度
final width = asset.width;            // 图片宽度
final height = asset.height;          // 图片高度
final fileSize = asset.fileSize;      // 文件大小
```

## 环境要求

- Flutter SDK >= 3.0.0
- 鸿蒙系统 API 9+
- 需要 `ohos.permission.READ_MEDIA` 权限（读取相册）
