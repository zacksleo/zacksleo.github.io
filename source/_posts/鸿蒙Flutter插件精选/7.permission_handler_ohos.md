# 鸿蒙Flutter插件精选：permission_handler_ohos —— 鸿蒙权限管理，一个插件全搞定

大家好呀～艾玛又来啦！🦊

上一期我们聊了 `flutter_rust_bridge_ohos`，带大家体验了 Dart 与 Rust 跨语言交互的奇妙世界。今天要聊的这个插件，可以说是**每个鸿蒙 Flutter 应用都绕不开**的刚需——

没错，就是 **权限管理**！📱

在鸿蒙（OpenHarmony）上开发 App，**权限申请**是一个基础但又容易踩坑的环节。不同权限有不同的申请方式（`system_grant` vs `user_grant`）、不同的权限级别（`normal` / `system_basic`），还要在 `module.json5` 里声明，稍不注意就弹不出授权弹窗。

而 **`permission_handler_ohos`** 就是来帮你一键解决这些烦恼的——由 [HarmonyCandies](https://github.com/harmonycandies) 社区出品，为 OpenHarmony 提供了一套简洁统一的权限管理 API！🚀

---

## 痛点

鸿蒙的权限体系虽然完善，但在 Flutter 开发中会遇到几个麻烦：

- **权限声明繁琐**：每个权限都要在 `module.json5` 中手动声明，不同权限有不同级别和授权方式
- **权限类型繁多**：总共有 44+ 种权限，分为 `system_grant`（系统授权）和 `user_grant`（用户弹窗授权），还有普通级别和 system_basic 级别，记起来真心累
- **鸿蒙版本迭代快**：不同 API 版本支持的权限不同，高版本可能新增或调整权限，手动同步很麻烦
- **没有 Flutter 原生封装**：直接用鸿蒙原生 API 需要写 MethodChannel 通道代码，繁琐易出错
- **权限状态难以管理**：检查权限状态、请求权限、打开设置引导，每一步都要处理边界情况

这要是每个权限都自己写 MethodChannel，项目里怕是得塞满一堆重复代码……😩

---

## 核心特性

- ✅ **44+ 权限枚举覆盖**：代码生成自官方 OpenHarmony 权限列表，涵盖 API 7~11 所有权限
- ✅ **双模式支持**：支持 `system_grant`（自动授权）和 `user_grant`（弹窗请求）两种权限类型
- ✅ **简单直观的 API**：检查权限、请求权限、打开设置，三个静态方法搞定
- ✅ **批量请求**：支持一次请求多个权限，返回 `Map<权限名, 状态>`，方便统一处理
- ✅ **权限详细元数据**：每个枚举包含权限名、权限级别、授权方式、ACL 使能状态、起始版本号
- ✅ **字符串兜底**：发现枚举中没有的权限时，可以直接传权限字符串全称，灵活兼容
- ✅ **打开设置引导**：用户拒绝授权后，一键跳转到系统设置页面，提升二次授权成功率
- ✅ **零额外依赖**：仅依赖 `flutter` 和 `plugin_platform_interface`，轻量无负担
- ✅ **和谐使者社区出品**：由 HarmonyCandies 组织维护，持续跟进鸿蒙版本更新

## 快速上手

### 1. 添加依赖

在 `pubspec.yaml` 中添加：

```yaml
dependencies:
  permission_handler_ohos: ^0.0.8
```

### 2. 配置 module.json5

在鸿蒙项目的 `entry/src/main/module.json5` 文件中，添加你要申请的权限声明：

```json
{
  "module": {
    "requestPermissions": [
      { "name": "ohos.permission.CAMERA" },
      { "name": "ohos.permission.MICROPHONE" },
      { "name": "ohos.permission.READ_MEDIA" },
      { "name": "ohos.permission.LOCATION" },
      { "name": "ohos.permission.APPROXIMATELY_LOCATION" }
    ]
  }
}
```

> ⚠️ **重要提醒**：`module.json5` 的声明是必需的！仅仅是 Flutter 端调用 API 是不够的，必须在鸿蒙原生侧提前声明权限。

### 3. 检查权限状态

```dart
import 'package:permission_handler_ohos/permission_handler_ohos.dart';

final PermissionStatusOhos status =
    await PermissionHandlerOhos.checkPermissionStatus(
  PermissionOhos.camera.name,
);

if (status == PermissionStatusOhos.granted) {
  print('📸 相机权限已获取，可以愉快拍照啦～');
} else if (status == PermissionStatusOhos.denied) {
  print('❌ 相机权限被拒绝，需要在设置中手动开启');
} else if (status == PermissionStatusOhos.invalid) {
  print('⚠️ 权限请求无效，请检查 module.json5 中是否声明了该权限');
}
```

### 4. 请求单个权限

```dart
final PermissionStatusOhos status =
    await PermissionHandlerOhos.requestPermission(
  PermissionOhos.camera.name,
);

if (status == PermissionStatusOhos.granted) {
  // 用户同意了！打开相机开始拍摄～
}
```

### 5. 批量请求权限

```dart
final Map<String, PermissionStatusOhos> statusMap =
    await PermissionHandlerOhos.requestPermissions([
  PermissionOhos.camera.name,
  PermissionOhos.microphone.name,
  PermissionOhos.read_media.name,
]);

// 检查每个权限的状态
statusMap.forEach((permission, status) {
  print('权限 $permission: ${status.name}');
});
```

### 6. 跳转系统设置

当用户拒绝权限后，引导用户去设置页面手动开启：

```dart
// 检查权限 -> 未授权 -> 引导去设置
final status = await PermissionHandlerOhos.checkPermissionStatus(
  PermissionOhos.location.name,
);

if (status == PermissionStatusOhos.denied) {
  // 显示提示：需要在设置中手动开启
  final opened = await PermissionHandlerOhos.openAppSettings();
  if (opened) {
    print('✅ 已跳转到系统设置页面');
  } else {
    print('❌ 无法打开设置页面');
  }
}
```

## 完整示例

下面是一个完整的权限请求流程，结合了检查 -> 请求 -> 引导设置的闭环：

```dart
import 'package:flutter/material.dart';
import 'package:permission_handler_ohos/permission_handler_ohos.dart';

class CameraScreen extends StatefulWidget {
  @override
  State<CameraScreen> createState() => _CameraScreenState();
}

class _CameraScreenState extends State<CameraScreen> {
  PermissionStatusOhos? _cameraStatus;
  bool _isRequesting = false;

  Future<void> _requestCameraPermission() async {
    setState(() => _isRequesting = true);

    try {
      // 1. 先检查当前状态
      final status = await PermissionHandlerOhos.checkPermissionStatus(
        PermissionOhos.camera.name,
      );

      if (status == PermissionStatusOhos.granted) {
        setState(() => _cameraStatus = status);
        return;
      }

      // 2. 请求权限
      final result = await PermissionHandlerOhos.requestPermission(
        PermissionOhos.camera.name,
      );

      if (result == PermissionStatusOhos.denied) {
        // 3. 被拒绝 → 引导用户去设置
        final opened = await PermissionHandlerOhos.openAppSettings();
        if (opened) {
          print('已跳转至设置页');
        }
      }

      setState(() {
        _cameraStatus = result;
        _isRequesting = false;
      });
    } catch (e) {
      print('权限请求异常: $e');
      setState(() => _isRequesting = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('相机权限示例')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(
              _cameraStatus == PermissionStatusOhos.granted
                  ? '✅ 相机权限已授权'
                  : '❌ 相机权限未授权',
              style: TextStyle(fontSize: 18),
            ),
            SizedBox(height: 20),
            ElevatedButton(
              onPressed: _isRequesting ? null : _requestCameraPermission,
              child: Text('请求相机权限'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## PermissionOhos 枚举一览

`permission_handler_ohos` 内置了 **44 种** OpenHarmony 权限枚举，覆盖了从 API 7 到 API 11 的所有常用权限。部分关键枚举如下：

| 权限枚举 | 对应权限名 | 授权方式 | 起始版本 |
|---------|-----------|---------|---------|
| `camera` | ohos.permission.CAMERA | user_grant | 9 |
| `microphone` | ohos.permission.MICROPHONE | user_grant | 8 |
| `location` | ohos.permission.LOCATION | user_grant | 7 |
| `approximately_location` | ohos.permission.APPROXIMATELY_LOCATION | user_grant | 9 |
| `read_media` | ohos.permission.READ_MEDIA | user_grant | 7 |
| `write_media` | ohos.permission.WRITE_MEDIA | user_grant | 7 |
| `read_calendar` | ohos.permission.READ_CALENDAR | user_grant | 8 |
| `write_calendar` | ohos.permission.WRITE_CALENDAR | user_grant | 8 |
| `access_bluetooth` | ohos.permission.ACCESS_BLUETOOTH | user_grant | 10 |
| `internet` | ohos.permission.INTERNET | system_grant | 9 |
| `vibrate` | ohos.permission.VIBRATE | system_grant | 7 |
| `accelerometer` | ohos.permission.ACCELEROMETER | system_grant | 7 |
| `gyroscope` | ohos.permission.GYROSCOPE | system_grant | 7 |

> 💡 **提醒**：如果某个权限不在枚举中，可以直接传权限字符串全称，比如：
> ```dart
> PermissionHandlerOhos.requestPermission('ohos.permission.READ_CONTACTS');
> ```

## 注意事项

1. **`module.json5` 声明是前提**：Flutter 端的 API 调用只负责弹窗和检查，权限声明一定要先在鸿蒙原生侧配好，否则返回 `invalid` 状态
2. **权限名称是字符串**：跨版本鸿蒙权限可能会有增减，可以灵活使用字符串传参替代枚举
3. **`system_grant` vs `user_grant`**：`system_grant` 权限安装时自动授权，不需要弹窗；`user_grant` 权限需要弹窗让用户确认
4. **权限级别限制**：部分系统级权限（`system_basic` 级别）普通应用无法申请，需要签名或申请 ACL
5. **后台位置权限特殊**：`LOCATION_IN_BACKGROUND` 不能通过弹窗获取，需要引导用户去设置页面手动开启
6. **API 兼容性**：插件当前依赖 `flutter >=3.7.0`，`sdk >=2.19.6 <3.0.0`，请确认项目满足版本要求
