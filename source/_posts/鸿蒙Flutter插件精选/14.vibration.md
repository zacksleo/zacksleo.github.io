# 鸿蒙Flutter插件精选：vibration —— 震动反馈，触感一致

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **tim_push** 解决了鸿蒙上的消息推送问题。今天介绍的插件虽然功能简单，但却是提升用户体验的重要细节——**震动触感**！

你有没有注意到，很多 App 在操作后会提供微弱的震动反馈——点击按钮、收到消息、扫码成功、游戏开火……这些都是靠震动来实现的。

但跨平台震动是个让人头疼的问题，Android、iOS、鸿蒙的震动 API 各不相同，参数也不一样。**vibration** 这个插件就是来解决这个问题的一一它提供了一个简单统一的 Flutter 震动接口，并且已经支持鸿蒙！

---

## 痛点

- **各平台震动 API 天差地别**：Android 有 `Vibrator` / `VibrationEffect`，iOS 有 `UIImpactFeedbackGenerator`，鸿蒙有 `@ohos.multimodalInput.vibrator`
- **震动参数不统一**：震动的时长、强度、模式在各平台语义完全不同
- **简单需求也要写大量原生代码**：只想轻轻「嗡」一下，却要写原生桥接，太小题大做了
- **不同设备的震动效果不一样**：马达类型不同，同样的参数在不同手机上震动体感差很多

---

## 核心特性

- ✅ **极简 API**：一行代码 `Vibration.vibrate()` 搞定震动
- ✅ **支持震动时长**：自定义震动持续时间（毫秒）
- ✅ **支持震动模式**：自定义震动节奏数组（开/关/开/关）
- ✅ **振幅控制**：支持震动强度设置（部分设备）
- ✅ **取消震动**：随时停止正在进行的震动
- ✅ **跨平台统一**：Android、iOS、OHOS 一套 API
- ✅ **鸿蒙原生适配**：自动调用鸿蒙 `@ohos.multimodalInput.vibrator` API

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  vibration: ^3.1.8
```

```bash
flutter pub get
```

### 2. 基础震动

```dart
import 'package:vibration/vibration.dart';

// 默认短震动（约 500ms）
Vibration.vibrate();

// 自定义时长（毫秒）
Vibration.vibrate(duration: 200);

// 震动模式 —— [震动ms, 停顿ms, 震动ms, ...]
Vibration.vibrate(pattern: [100, 50, 100, 50, 200]);

// 带振幅的震动（仅支持振幅的设备）
Vibration.vibrate(amplitude: 128, duration: 300);

// 取消震动
Vibration.cancel();
```

### 3. 检测设备是否支持震动

```dart
final hasVibrator = await Vibration.hasVibrator();
final hasAmplitudeControl = await Vibration.hasAmplitudeControl();

if (hasVibrator) {
  Vibration.vibrate();
} else {
  print('设备不支持震动');
}
```

### 4. 实际场景示例

```dart
// 扫码成功 —— 短促震动反馈
void onScanSuccess() {
  Vibration.vibrate(duration: 100);
  showSnackBar('扫码成功！');
}

// 收到消息 —— 典型的 3 次短震模式
void onMessageReceived() {
  Vibration.vibrate(pattern: [100, 50, 100, 50, 100]);
}

// 游戏开火 —— 短而有力的震动
void onFire() {
  Vibration.vibrate(amplitude: 255, duration: 50);
}

// 错误操作 —— 持续低幅震动
void onError() {
  Vibration.vibrate(pattern: [300, 100, 300], amplitudes: [100, 0, 100]);
}
```
