# 鸿蒙Flutter插件精选：petalmaps_ohos —— 花瓣地图，鸿蒙原生导航新选择

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **flutter_image_compress_plus_ohos** 的另一套压缩方案。今天要介绍的插件是地图领域的另一位选手——**花瓣地图（Petal Maps）**！

你可能会问：华为地图（`huawei_map_ohos`）和花瓣地图（`petalmaps_ohos`）有什么区别？

简单来说：**华为地图**是华为 Map Kit 的基础地图能力（展示地图、标点、路线）；而 **花瓣地图**是华为的消费者地图 App 品牌的 SDK 版本，更侧重于导航、实时交通、周边搜索等出行场景。

如果你的 App 需要更丰富的地图能力，特别是导航和出行服务，那 `petalmaps_ohos` 就是你的选择！🗺️

---

## 痛点

- **地图能力需求升级**：仅仅展示地图不够了，还需要实时导航、实时路况、公交路线规划
- **高德百度在鸿蒙上体验打折扣**：第三方地图 SDK 虽然也能用，但性能、弹性和流畅度不如原生的
- **花瓣地图在国内有独特优势**：基于华为自研的地图引擎，在中国大陆地区数据准确度高
- **用户更习惯花瓣地图 App 的体验**：花瓣地图在鸿蒙手机上是预装应用，用户已经习惯了它的交互

---

## 核心特性

- ✅ **地图展示**：标准地图、卫星地图、交通流量图
- ✅ **实时导航**：支持驾车、步行、骑行导航模式
- ✅ **路线规划**：驾车路线、公交路线、步行路线、骑行路线
- ✅ **实时路况**：实时交通流量显示
- ✅ **POI 搜索**：关键字搜索、周边搜索、热门搜索
- ✅ **地理编码**：地址转坐标、坐标转地址
- ✅ **位置选择器**：内置位置选择 UI 组件
- ✅ **当前位置**：获取和展示设备当前位置
- ✅ **与华为地图协同**：和 `huawei_map_ohos` 互补使用

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  petalmaps_ohos: ^0.0.1
```

```bash
flutter pub get
```

### 2. 权限配置

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      },
      {
        "name": "ohos.permission.APPROXIMATELY_LOCATION"
      },
      {
        "name": "ohos.permission.LOCATION"
      },
      {
        "name": "ohos.permission.ACCESS_BLUETOOTH"
      }
    ]
  }
}
```

### 3. 初始化并展示地图

```dart
import 'package:petalmaps_ohos/petalmaps_ohos.dart';

class MapPage extends StatefulWidget {
  @override
  _MapPageState createState() => _MapPageState();
}

class _MapPageState extends State<MapPage> {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('花瓣地图')),
      body: PetalMapWidget(
        initialCameraPosition: CameraPosition(
          target: LatLng(39.9042, 116.4074),
          zoom: 14,
        ),
        onMapCreated: (controller) {
          // 地图创建完成
        },
        markers: {
          Marker(
            markerId: MarkerId('current'),
            position: LatLng(39.9042, 116.4074),
            icon: BitmapDescriptor.defaultMarker,
          ),
        },
      ),
    );
  }
}
```

### 4. POI 搜索

```dart
final searchResult = await PetalMapSearch.searchPOI(
  keyword: '餐厅',
  location: LatLng(39.9042, 116.4074),
  radius: 1000, // 搜索半径（米）
);

for (final poi in searchResult.pois) {
  print('${poi.name} - ${poi.address} - ${poi.distance}m');
}
```

### 5. 路线规划

```dart
// 驾车路线规划
final route = await PetalMapRouting.driveRoute(
  start: LatLng(39.9042, 116.4074),
  end: LatLng(39.9142, 116.4174),
  alternatives: true, // 请求备选路线
);

if (route.isNotEmpty) {
  final mainRoute = route.first;
  print('预计距离: ${mainRoute.distance}m');
  print('预计时间: ${mainRoute.duration}分钟');
  
  // 在地图上绘制路线
  mapController?.addPolyline(
    Polyline(
      polylineId: PolylineId('route'),
      points: mainRoute.pathPoints,
      color: Colors.blue,
      width: 6,
    ),
  );
}
```

### 6. 打开导航

```dart
// 打开花瓣地图 App 进行导航
await PetalMapNavigator.navigateTo(
  destination: LatLng(31.2304, 121.4737), // 上海
  destinationName: '东方明珠',
  mode: NavigationMode.driving, // driving | walking | cycling
);
```

## 环境要求

- Flutter SDK >= 3.0.0
- 华为开发者联盟账号（已开通 Petal Maps SDK）
- 鸿蒙系统 API 9+
- 花瓣地图 App（用于导航跳转，非必需）

---

> 花瓣地图和华为地图并不是「二选一」的关系，它们是互补的——
>
> - 需要**展示地图 + 标点 + 路线**？用 `huawei_map_ohos`
> - 需要**POI 搜索 + 导航 + 实时交通**？用 `petalmaps_ohos`
> - **两个一起用**，体验最完整！
>
> 而且都是华为系的，API 风格类似，学习成本很低。所见即所得，出活快！🚗
