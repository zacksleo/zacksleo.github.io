# 鸿蒙Flutter插件精选：flutter_ohos_ads —— 鸿蒙广告变现，一行代码接入

大家好呀～艾玛又来啦！🦊

上一期我们聊了 **permission_handler_ohos** 解决了鸿蒙权限管理的难题。今天要聊的这个插件可是关乎开发者「恰饭」的大事——**广告变现**！

对开发者来说，App 做广告变现是再正常不过的需求了。但鸿蒙平台上想接入广告，之前的流程是这样的：

1. 去华为开发者联盟申请 Ads Kit
2. 配置签名证书
3. 写一堆 ArkTS 原生代码
4. 处理广告生命周期和回调……
5. Android 和 iOS 还各有一套代码 😩

现在好了，**flutter_ohos_ads** 直接把华为 Ads Kit 的 Banner、插屏、激励视频等广告类型封装成了 Flutter 插件，一行代码搞定！

---

## 痛点

- **原生集成门槛高**：对接华为 Ads Kit 需要熟悉 ArkTS、配置签名、处理权限，新手直接劝退
- **多平台代码重复**：Android 用 google_mobile_ads，iOS 用 Admob，鸿蒙又来一套，项目结构越来越臃肿
- **广告配置复杂**：广告位 ID、测试模式、回调处理……每次都要重复造轮子
- **生命周期管理麻烦**：广告加载、展示、关闭、错误处理的回调链又长又容易漏

---

## 核心特性

- ✅ **跨平台统一 API**：Flutter 层一套代码，三端（Android/iOS/HarmonyOS）共享
- ✅ **支持主流广告类型**：Banner 横幅、插屏广告、激励视频、原生广告
- ✅ **测试模式支持**：开发阶段使用测试广告 ID，避免误触广告政策
- ✅ **生命周期自动管理**：页面销毁时自动释放广告资源，防止内存泄漏
- ✅ **事件回调完整**：加载成功、加载失败、曝光、点击、关闭等全链路回调
- ✅ **零侵入集成**：无需修改原有 Android/iOS 广告代码，只加鸿蒙实现

## 快速上手

### 1. 添加依赖

```yaml
dependencies:
  flutter_ohos_ads: ^1.0.1
```

```bash
flutter pub get
```

### 2. 配置广告位

在 `ohos/entry/src/main/module.json5` 中添加广告权限：

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      }
    ]
  }
}
```

> 注意：鸿蒙广告需要在华为开发者联盟开通 **Ads Kit** 服务并获取广告位 ID。

### 3. 展示 Banner 广告

```dart
import 'package:flutter_ohos_ads/flutter_ohos_ads.dart';

class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('鸿蒙广告示例')),
      body: Column(
        children: [
          Expanded(child: YourContent()),
          // 底部 Banner 广告
          OhosBannerAd(
            adUnitId: 'testw6vs28auh3', // 测试广告位 ID
            width: 320,
            height: 50,
            onAdLoaded: () => print('广告加载成功'),
            onAdFailed: (error) => print('广告加载失败: $error'),
            onAdClicked: () => print('广告被点击'),
          ),
        ],
      ),
    );
  }
}
```

### 4. 展示插屏广告

```dart
final interstitialAd = OhosInterstitialAd(
  adUnitId: 'testb4znbuh3n2',
);

// 加载并展示
await interstitialAd.load();
await interstitialAd.show();
```

### 5. 展示激励视频广告

```dart
final rewardAd = OhosRewardedAd(
  adUnitId: 'testx9jswrjpn7o',
);

await rewardAd.load();
await rewardAd.show(
  onUserEarnedReward: (reward) {
    print('用户获得奖励: ${reward.amount} ${reward.type}');
    // 发放奖励给用户 🎁
  },
);
```

## 环境要求

- Flutter SDK >= 3.0.0
- 华为开发者联盟账号（已开通 Ads Kit 服务）
- 鸿蒙系统 API 9+
- 需要真机或云真机测试（模拟器不支持广告展示）
